# Agent Studio overview

> Hire built-in agents or build your own, and put them to work in Zuper Sense.

Agent Studio is where Zuper Sense's agents live. Some answer questions in chat, others run in the background and post to Zuper Chat or email. Pick one from the Marketplace, or build your own.

## What an agent is

An agent is an automated, configured worker designed to handle specific tasks. Every agent consists of a standard set of core components, including its configuration, instructions, triggers, knowledge base, and tools. To learn more about how these components work, see [**Agent Anatomy**](/Zuper_Sense/Agent_Studio/Agent_Anatomy).

* Pre-built agents provided by Zuper that you can configure and deploy, such as the [CSR](/Zuper_Connect/CSR-Agent), [Weather](/Zuper_Sense/Marketplace_Agents/Weather_Agent) or [Reputation agent](/Zuper_Sense/Marketplace_Agents/Reputation_Agent).
* Fully custom agents built tailored to your unique operational processes ***→*** <Badge color="purple">Coming Soon</Badge>
* For example, the **Business Intelligence** agent is the one giving insights in your questions on Sense chat.

## Agent status types

The status badge on any card under **My Agents** indicates its current operational state:

<table>
  <colgroup>
    <col width="107" />

    <col width="325" />
  </colgroup>

  <thead>
    <tr>
      <th>Status</th>
      <th>Definition</th>
    </tr>
  </thead>

  <tbody>
    <tr>
      <td>**Active**</td>
      <td>Deployed and actively monitoring or responding to configured triggers.</td>
    </tr>

    <tr>
      <td>**Draft**</td>
      <td>Configured but not yet deployed; does not execute on triggers.</td>
    </tr>

    <tr>
      <td>**Paused**</td>
      <td>Previously deployed but temporarily halted; ignores triggers until manually resumed.</td>
    </tr>
  </tbody>
</table>

## Getting started

To explore available agents, select **Browse marketplace** from the **My Agents** tab to view pre-built capabilities, or select any existing agent card to modify its settings and instructions.
