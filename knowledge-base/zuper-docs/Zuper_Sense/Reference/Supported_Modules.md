# Supported modules

> The parts of Zuper that Zuper Sense can answer questions on, with an example question for each.

Zuper Sense reads the modules below straight from your account. There is nothing to connect or switch on. Ask naturally and Sense picks the right module for the question.

## How to ask

* Ask in plain language, the way you'd ask a coworker. "How many purchase orders are still open?" works as well as any report filter.
* Name a job number, customer or organization when you have one, so Sense finds the record straight away.
* One question can span modules. "Does the purchase order for job #1234 match what was invoiced?" reads three of them at once.

<Note>Sense answers from the records you are allowed to see. It never widens your access.</Note>

## Modules Sense can answer on

Every module below supports both Insights and Reasoning. Ask for a number or a trend, or ask why something happened, and Sense will use the same data either way.

| Module | Ask for insights | Ask why |
| - | - | - |
| Jobs | "Which jobs are delayed this week?" | "Why was job #1234 delayed?" |
| Measurements | "What measurements were recorded for job #1234?" | "Why don't the measurements match the estimate?" |
| Contacts | "Which customers haven't paid?" | "Why hasn't this customer paid yet?" |
| Organizations | "How many jobs have we done for Apex Roofing?" | "Why did Apex Roofing's job count drop this quarter?" |
| Properties | "How many properties do we service for this customer?" | "Why does this property need more frequent service calls?" |
| Quotes & Proposals | "How is my quote pipeline looking?" | "Why haven't these quotes converted?" |
| Proposal Options | "Which proposal option gets picked most often?" | "Why do customers pick the premium option less often?" |
| Pricelists | "Which pricelist has the most line items?" | "Why is this pricelist rarely used?" |
| Invoices | "How is my revenue trending?" | "Why did this invoice go out later than usual?" |
| Payments | "Which invoices are still unpaid?" | "Why is this payment overdue?" |
| Commissions | "How much commission is owed this month?" | "Why is this rep's commission lower this month?" |
| Financing | "How many jobs are using financing right now?" | "Why was this job's financing declined?" |
| Profitability | "What's my profit margin on job #1234?" | "Why is this job's margin lower than expected?" |
| Parts & Services | "Which products were used most in jobs this quarter?" | "Why did this job use more parts than estimated?" |
| Material Requests | "How many material requests are still pending?" | "Why is this material request still pending?" |
| Purchase Orders | "How many purchase orders are still open?" | "Why is this purchase order still open?" |
| Vendors | "Which vendors had late deliveries this month?" | "Why was this delivery late?" |
| Timesheets | "Show total work hours by employee for the last 30 days" | "Why did this employee log overtime this week?" |
| Teams & Users | "How did my team perform this quarter?" | "Why did this team's performance drop?" |
| Sales Coach | "Which competitor comes up most often in our sales calls?" | "Why did we lose this deal to a competitor?" |

## Asking about Zuper itself

Alongside your data, Sense answers [**questions about how to use Zuper**](/Zuper_Sense/Ask_Sense/Zuper_Help), such as "How do I set up tasks?", and cites the help articles behind the answer.
