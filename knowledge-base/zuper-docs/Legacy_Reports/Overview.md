# Overview of Legacy Reports

## Key Features

* **Comprehensive Data Access**: Retrieve data on work orders, jobs, projects, and customer interactions from legacy databases.
* **Customizable Reports**: Select specific date ranges and modules to tailor reports to your business needs.
* **Historical Insights**: Monitor trends and performance metrics from pre-upgrade data to support decision-making.
