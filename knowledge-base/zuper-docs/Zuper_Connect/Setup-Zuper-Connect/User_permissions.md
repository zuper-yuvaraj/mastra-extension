# Manage User Permissions

In Zuper Connect, managing user permissions ensures that the right team members have access to the communication features they need to stay connected and productive.

By configuring permissions, users can:

* Efficiently make and receive calls from customers or internal team members through the Zuper Phone interface within the app.
* Access the Zuper Connect Inbox/Conversations for a unified view of all communication threads.
* Access Call Logs to review call history, status, recordings, and related interactions.

**User Role: Admin (if assigned)**

The following communication features can be accessed on different platforms:

| **Feature** | **Web** | **Mobile** |
| :- | :- | :- |
| Zuper Phone | Yes | Yes |
| Conversations | Yes | No |
| Call Logs | Yes | Yes |

**User Role: Team leaders/Field technicians (if assigned)**

The following communication features can be accessed on different platforms:

| **Feature** | **Web** | **Mobile** |
| :- | :- | :- |
| Zuper Phone | No | Yes |
| Conversations | No | No |
| Call Logs | No | Yes |

## Add a new user

To add a new user,

* Click the “**+ Add User**” button on the user's listing page. A dialog box will appear.

<img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/user2.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=59c1da07cb49ec1473a734ffd7863017" alt="User2 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/user2.png" />

* Add the user(s) you want to grant access to Zuper connect.
* Once added, click the “**Add Users**” button. A confirmation message will appear indicating that the user(s) have been successfully added.

<img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/user3.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=330899422f571ee769ad886d0717d5b4" alt="User3 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/user3.png" />

## Add user to a call group (Optional)

Once permissions are granted for the selected users, you can optionally assign them to a call group. This helps streamline communication by grouping team members who handle similar tasks or customer calls, ensuring calls are routed efficiently and reach the right people at the right time. To do this, follow these steps:

* Click the “**Add to Group**” button next to the user. <img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/user4.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=1fa798beaa619436cbdd98189983ef69" alt="User4 Pn" width="1906" height="779" data-path="Zuper_Connect/Setup-Zuper-Connect/user4.png" />
* A list of existing call groups will appear. (For details on creating call groups, refer to the “[How to Create a Call Group](https://docs.zuper.co/Zuper_Connect/Setup-Zuper-Connect/Call_groups)” guide.)
* Select the desired group by clicking “**Add**” next to it.
* Click “**Done**” to save the changes. <img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/user5.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=989e8352e672b669b989846d9920d755" alt="User5 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/user5.png" />

## Managing users

After adding users who have access to Zuper Connect, admins can manage these users directly from the User Permissions listing page. You can **edit** user details or **deactivate** users as needed.

### **Edit a User**

To modify user details:

1. On the **User Permissions** listing page, click the<Icon icon="ellipsis-vertical" color="#0c0c0c" /> icon next to the user you want to modify.
2. Select **Edit Details** from the dropdown menu. <img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/user6.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=1ad09d678c373c5ec1c7edee8e4311c2" alt="User6 Pn" width="1905" height="819" data-path="Zuper_Connect/Setup-Zuper-Connect/user6.png" />
3. In the **Edit User** dialog box, you can:
   * **Call Groups** – Add or remove call groups associated with the user.
4. Click **Update User** to save your changes.

### **Deactivate a User**

To remove a user’s access:

1. On the **User Permissions** listing page, click the<Icon icon="ellipsis-vertical" color="#060606" />icon next to the user you want to modify.
2. Select **Deactivate User** from the dropdown menu. <img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/user7.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=42ed4e8ff2510b1150e880520473ee8a" alt="User7 Pn" width="1905" height="819" data-path="Zuper_Connect/Setup-Zuper-Connect/user7.png" />
3. A confirmation dialog box will appear.
4. Click **Deactivate** to revoke the user’s access.
