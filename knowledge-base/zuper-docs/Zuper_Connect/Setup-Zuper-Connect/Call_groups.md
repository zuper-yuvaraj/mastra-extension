# Creating Call Groups

Call groups are an effective way to route incoming calls to multiple users simultaneously within your Zuper Connect account, ensuring faster response times and improved customer service. 

Call groups are typically used with call routing, which directs incoming calls to the appropriate group, ensuring customers are quickly connected to the right person or department. To learn more, see [How to Create a Call Route](https://docs.zuper.co/Zuper_Connect/Setup-Zuper-Connect/call_routing).

In this article, you’ll learn how to create a new call group in Zuper Connect. By setting up a call group, multiple users can receive calls at the same time, minimizing wait times and enhancing overall customer satisfaction. 

#  Access call group settings 

* Select the “**Settings**” module from the left navigation menu. 
* On the settings page, click “**Zuper Connect**.” The Zuper Connect settings page will appear.
* Select “**Call Settings**.” You will land on the call groups listing page, displaying group names, the number of users assigned to each group, and the associated call routings.

# Create a new call group 

To create a new call group,

* Click the “**+ New Group**” button on the call groups listing page.

<img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/callgroup1.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=eb08e7621ad03b444a764914504eeb52" alt="Callgroup1 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/callgroup1.png" />

* A dialog box will appear to create a new call group.
  1. **Group name**: Enter the name of the group you are creating.
  2. **Members in group**:   Add all of the users you want to include in this call group. 

<img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/callgroup2.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=8744d6983ef94e2896fd94c9ba52810b" alt="Callgroup2 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/callgroup2.png" />

<Note>
  **Note**: Only users who have access to Zuper connect will be displayed for selection. For more details, see <u>Manage user permissions.</u> 
</Note>

* Click “**Create**."

The group will be created successfully, and it will now be available for use when configuring your call route. 

## Edit a call group 

* On the **Call Groups** listing page, click the <Icon icon="pencil" color="#070707" /> icon next to the call group you want to update. 

<img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/callgroup3.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=21a0e6f93dce22469759df9477eecbf9" alt="Callgroup3 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/callgroup3.png" />

* The **Update Call Group** dialog box will open, allowing you to make the following modifications: 
  1. **Call Group Name**: Update the name of the group as needed. 
  2. **Group Members**: Add new members to the group or remove existing ones. 
* Click **Update** to apply your changes. 

## Delete a call group 

* On the **Call Groups** listing page, click the <Icon icon="trash-can" color="#030303" /> icon next to the call group you want to delete.

<img src="https://mintcdn.com/zuperinc/CnXsaVzX1o8zG7qq/Zuper_Connect/Setup-Zuper-Connect/callgroup4.png?fit=max&auto=format&n=CnXsaVzX1o8zG7qq&q=85&s=ecabf7adc41a9d9454cc2602c5f2b7d6" alt="Callgroup4 Pn" width="1920" height="878" data-path="Zuper_Connect/Setup-Zuper-Connect/callgroup4.png" />

* A confirmation dialog box appears.
* Click **Delete** to delete the phone number. 

<Note>
  **Note**: Deleting a call group will remove it from any associated call routings. To ensure uninterrupted call management, assign a new group to handle incoming calls. 
</Note>
