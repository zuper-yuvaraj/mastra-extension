# Overview 

Projects allow field service providers to plan and manage undertakings that span over longer periods of time and involve multiple jobs, people, and materials. Below are some of the key features in Projects: 

* **Phases, Milestones, and Dependencies**: Create comprehensive project plans by grouping jobs and milestones into phases and managing dependencies between jobs and milestones. 
* **Manage finances**: Quotes and invoices can be created and managed from a project. We have more comprehensive capabilities coming up to manage finances end-to-end.
* **Parts & Services**: Plan and track consumption of parts & services within a project.
* **Time logs**: Technicians can clock into a project from a mobile device. On the web, they can access the time logs of all users in the project and group them by Users, Jobs, or Date.
* **Access projects from mob**ile: The Zuper V3 mobile app allows you to clock in, track progress, add a quick note, and update project status on the go.
