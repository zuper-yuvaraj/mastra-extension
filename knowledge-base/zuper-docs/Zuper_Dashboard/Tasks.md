# Managing Tasks

Tasks help you organize and track activities that you or your team members need to complete, without requiring the creation of a formal job for them. Unlike a service job, tasks offer the flexibility to manage work independently or associate them with jobs or projects when they are part of ongoing work.

<Check>
  **Prerequisite**: Ensure that the **Tasks** feature is enabled for your organization. If it is not enabled, contact our support team at [support@zuper.co](mailto:support@zuper.co) to have it enabled.
</Check>

## Create a new task

You can create a task in two ways in Zuper:

1. **From the Task list:** Click **Create Task** in the **Task List** side panel, which you can access by clicking the **Tasks** icon in the top-right corner of the header bar. <img src="https://mintcdn.com/zuperinc/DX51gbHz-m2uHKy6/Zuper_Dashboard/addtask.png?fit=max&auto=format&n=DX51gbHz-m2uHKy6&q=85&s=b03569eca41dba718d74ac2763fc31bb" alt="Addtask" width="1920" height="911" data-path="Zuper_Dashboard/addtask.png" />
2. **From a Job or Project:** Click **Create Task** on the **Tasks** section on a job or project page. When you create a task from a job or project, it will automatically be associated with that job or project. <img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/tasks-1.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=44f2a59106187d35d333bfd70f41d491" alt="Tasks 1" width="1920" height="869" data-path="Zuper_Dashboard/tasks-1.png" />

The following information will be prompted to fill in for creating a task.

1. **Task Name**: A task name is required for every task you create. Give your task a clear, descriptive name.
2. **Task Description**: The description is optional but may be used to classify what is expected.
3. **Priority**: Set none, low, medium, or high priority level to help the assignee understand how to accommodate the task in their schedule.
4. **Assignee**: Assign the task to yourself or a team member. This will send a push notification to the team member assigned to the task. If you added someone by accident, you can unassign them by clicking the **X** next to their name. 
   <Note>
     **Note**: *Only one user can be assigned to a task*.
   </Note>
5. **Task Type**: Choose a task type from the predefined list. By default, it is set to **Task**, but you can change it if needed.
6. **Associated** **module**: Link the task to a specific Job or Project to keep work traceable and connected.
7. **Due Date**: Specify when the task should be completed. Tasks that are due today are highlighted in amber, and tasks that passed the due date are highlighted in red to indicate they are overdue.
8. **Set Reminder**: Schedule reminders to help the assignee act on time.
9. **Inspection Form**: Select an inspection form and associate it with the task when the inspection must be completed before the task is closed.
10. **Attachments**: Upload relevant files or documents to support the task with additional context or details.
11. After entering all the required details, click “**Create**” to save the task. <img src="https://mintcdn.com/zuperinc/DX51gbHz-m2uHKy6/Zuper_Dashboard/Tasking-14.gif?s=7b8b42e59d640f10a317618f2e03bab0" alt="Tasking 14" width="1920" height="869" data-path="Zuper_Dashboard/Tasking-14.gif" />

<Tip>
  **Tips**: To save time, create tasks using templates. Click on “**Choose a task template**” to search and choose the relevant task from the master list. The selected master task will automatically fill in the details on the creation page.

  <img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/template.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=fe0bdb8bbbf845f66bd744d31907c87d" alt="Template" width="1920" height="869" data-path="Zuper_Dashboard/template.png" />
</Tip>

### Working in the Task list panel

When you open the task panel, you can:

* Expand the panel to full screen by using the **Expand** icon in the top-right corner for better visibility. <img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/tasks-5.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=904bad51709d627f43241d5a057a1cf1" alt="Tasks 5" width="894" height="269" data-path="Zuper_Dashboard/tasks-5.png" />
* Toggle **Include Team Tasks**  to *On* to view tasks assigned to your team. Note: Admins and Team Leads can see the tasks of their team members, while Field Techs can only view their own tasks. <img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/tasks-6.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=66c2e8b5ec45176da38e0644431273d3" alt="Tasks 6" width="896" height="274" data-path="Zuper_Dashboard/tasks-6.png" />
* **Search** for tasks by name. <img src="https://mintcdn.com/zuperinc/-p-PJBpk3jpqDn_E/Zuper_Dashboard/searchtask.png?fit=max&auto=format&n=-p-PJBpk3jpqDn_E&q=85&s=86e79815fd683fceb562d09e20e9e62b" alt="Search" width="859" height="437" data-path="Zuper_Dashboard/searchtask.png" />
* **Filter** the task based on priority, task type, assignee, status, and due date. To do so, click on the **Filter** icon, and in the filter panel, you can apply the filters to narrow down the tasks. <img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/tasks-7.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=c4ee0ed656aa7230c525a868ef508ac4" alt="Tasks 7" width="856" height="529" data-path="Zuper_Dashboard/tasks-7.png" />
* You can switch between the **tabs** at any time to manage tasks based on their progress.
  * **Open Tab:** Automatically shows tasks with open statuses (Yet to Start, In Progress, On Hold, Completed, and so on)
  * **Due Tab:** Displays tasks that are due today by default. You can apply additional filters such as overdue, yesterday, last 7 days, last 30 days, this month, last month, or a custom date range to view tasks due within your preferred timeframe.
  * **All Tab:** Shows all tasks <img src="https://mintcdn.com/zuperinc/DX51gbHz-m2uHKy6/Zuper_Dashboard/alltabs.png?fit=max&auto=format&n=DX51gbHz-m2uHKy6&q=85&s=0814d0f285ddf15e0eb281a599239bb7" alt="Alltabs" width="859" height="437" data-path="Zuper_Dashboard/alltabs.png" />

### Updating task status

To update the status of a task:

1. Click the **radio button** next to the task. <img src="https://mintcdn.com/zuperinc/-p-PJBpk3jpqDn_E/Zuper_Dashboard/radiotask.png?fit=max&auto=format&n=-p-PJBpk3jpqDn_E&q=85&s=5d152c944ca9bbfb6385e735e9e99984" alt="Radiotask" width="1920" height="869" data-path="Zuper_Dashboard/radiotask.png" />
2. Choose the relevant status.
3. (Optional) Enter remarks to provide clarity on the update.

<Note>
  **Note**: If a task has an inspection form attached, you’ll be prompted to complete the inspection before marking the task as **Completed**.
</Note>

You can manage your task with these options:

<img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/listcontext.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=6d80db69decb8042f11b5eaa99bb5020" alt="Listcontext" width="1920" height="869" data-path="Zuper_Dashboard/listcontext.png" />

* **Edit**: You can modify the task details. However, the assignee cannot be changed from this option.
* **Clone**: You can create an exact copy of the task, preserving its fields and settings.
* **Task Status History**: It displays a chronological log of all status changes, including who updated the task, when the update was made, and any remarks recorded during the status change.
* **Remove**: You can delete a task you no longer need to keep your workspace tidy.

## Associating tasks with jobs and projects

Tasks in Zuper can be simple, standalone items, or part of a larger workflow within a job or project. When a task contributes to a specific service activity, Zuper makes it easy to establish that connection.

If you’re creating a task that belongs to a job or project, just **select** the related Job or Project in the **Associated Module** field on the task creation page. It takes only a second, but it keeps everything neatly organized.

### Viewing associated tasks

All tasks associated with a job or project appear in the **Tasks** section on the detail page. This gives you a complete view of all work items for that specific job or project.

<img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/jobtasks.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=dea9e980be81edb483ed69662392ac2a" alt="Jobtasks" width="1920" height="869" data-path="Zuper_Dashboard/jobtasks.png" />

Users with access to the job or project will also be able to view its associated tasks.

#### Reordering task

When a job or project contains multiple tasks, you can define the exact order in which they should be completed.

1. In the **Tasks** section, click the More Actions (kebab menu) and select **Re-order Tasks**. <img src="https://mintcdn.com/zuperinc/-p-PJBpk3jpqDn_E/Zuper_Dashboard/reordertask.png?fit=max&auto=format&n=-p-PJBpk3jpqDn_E&q=85&s=bb34bcb2fff0515f894b6c127ca3bca9" alt="Reordertask" width="1920" height="869" data-path="Zuper_Dashboard/reordertask.png" />
2. The list switches to reorder mode.
3. Drag and drop tasks to rearrange them. <img src="https://mintcdn.com/zuperinc/-p-PJBpk3jpqDn_E/Zuper_Dashboard/taskreorder.png?fit=max&auto=format&n=-p-PJBpk3jpqDn_E&q=85&s=0f6788ea61136fc5b4c50b203e131f52" alt="Taskreorder" width="1920" height="869" data-path="Zuper_Dashboard/taskreorder.png" />
4. Click **Done**(tick icon) to save the order or **Cancel** to discard.

#### Task execution mode

You have flexibility in determining how tasks should be executed. Zuper supports two execution modes:

1. **Parallel Execution** (Default) - Tasks can be completed in any order. This is the default execution mode and works best when multiple team members can work independently without waiting for other tasks to finish.
2. **Serial Execution** - Tasks must be completed in a specific sequence. This is useful when one task depends on the successful completion of the previous one, for example, inspection before installation.

You can switch between serial and parallel execution by opening the **More Actions** menu in the Tasks section.

<img src="https://mintcdn.com/zuperinc/FS3wvIzFdIIWiXVs/Zuper_Dashboard/parallel.png?fit=max&auto=format&n=FS3wvIzFdIIWiXVs&q=85&s=697d1371e5bbab34d2a2595fcfcf98ae" alt="Parallel" width="1920" height="869" data-path="Zuper_Dashboard/parallel.png" />

### FAQs

<AccordionGroup>
  <Accordion title="Can I create recurring tasks?">
    No. However, you can use the **Clone** feature to quickly duplicate tasks.
  </Accordion>

  <Accordion title="Can I track who changed the task and when?">
    Yes. Use **Task Status History** to view a chronological log of all status changes, including who updated the status, when it was updated, and any remarks added during the update. Other task updates — such as edits to task details — are recorded in the **Job Activity** log when the task is associated with a job.
  </Accordion>

  <Accordion title="Can I complete a task without filling in its inspection form?">
    No. If an inspection form is associated with the task, Zuper requires it to be completed before the task status is changed to **Completed**.
  </Accordion>

  <Accordion title="What is a Master Task Template in Zuper?">
    A [Master Task Template](https://docs.zuper.co/Settings/Modules/Jobs/configuring-service-tasks#configuring-service-tasks) is a pre-configured task created within Zuper. When selected during task creation, this template automatically fills in the task form with predefined details from the service task.
  </Accordion>

  <Accordion title="Can I complete a project without completing the associated tasks?">
    Yes. You can mark the project as **Complete** even if not all tasks under it are completed.
  </Accordion>

  <Accordion title="Can I complete a job without completing the associated tasks?">
    No. All tasks associated with a job must be completed before the job can be marked as **Completed**.
  </Accordion>

  <Accordion title="How is the due date set when I create a task from a template?">
    When you create a task using a task template (master task), the due date is automatically calculated based on the **estimated duration** defined in the template. For example, if the template has an estimated duration of 5 days, the task's due date will be set to 5 days from the date you create the task. You can manually change the due date before saving.
  </Accordion>

  <Accordion title="How can I change the assignee for a task?">
    You can change the assignee only from the **Task List** view. Click the assignee avatar on the task row and select a different user.
  </Accordion>

  <Accordion title="Why is the user assigned to a task also showing up as an assignee on the parent job or project?">
    This is expected behavior. When the **Automatically add task assignees to the job/project** setting is turned on, anyone assigned to a task is also added as an assignee to the related job or project. This ensures the right people have visibility and access to the job or project the task belongs to.

    If you don't want this, an Admin can turn it off under: **Settings → Modules → Jobs (or Projects) → General Settings → Assignment tab**.
  </Accordion>

  <Accordion title="Why can't I update the status of a Service Task?">
    If you see an error blocking a task status update, check whether the job's **Task Execution Mode** is set to **Serial**. In Serial mode, tasks must be completed in the configured sequence — you cannot update a later task's status until the preceding task (the one it depends on) has been marked complete.

    To resolve this:

    1. Complete the blocking/dependent task first.
    2. If the serial order is unintentional, an Admin can change the execution mode to **Parallel** from the job's Task section.
  </Accordion>
</AccordionGroup>
