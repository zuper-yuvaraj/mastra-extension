# Search in Chat

The Search feature in Chat helps you quickly:

* Locate specific users, messages, and channels across the chat module.
* Sort message results by creation date.
* Filter message results by sender or channel.

<Tabs>
  <Tab title="Web">
    - Click the Search <Icon icon="magnifying-glass" /> icon at the top right of the Chat sidebar.
    - Type your keyword — for example, a user’s name, message content, or channel name.
    - The search window displays categorized results under:
      1. **Messages** – Displays messages that include the search term.
      2. **Users** – Lists users whose names match your search term.
      3. **Channels** – Shows channels containing the keyword in their title.

    **Using Filters in Search (Messages Only)**

    Filters are available when the **Messages** tab is selected, and help refine your results:

    You can organize and narrow results using the following options:

    * **Sort** (Created At): Use the Sort option to organize message results by their created date (Newest or Oldest).
    * **From**: Select and view messages shared by a specific user.
    * **In:** Select and view the channels where the message was sent.

    After applying the required filters, select a search result to open the corresponding conversation directly.

  </Tab>

  <Tab title="Mobile">
    * In Chat Home, tap the Search bar.
    * Enter a keyword to search across DMs, channels, and messages. Results will be categorized under Messages, Channels, and Users.

    **Using Filters in Search (Messages Only)**

    Filters appear only within the Messages tab:

    * Tap **Sort & Filter** to organize results by:
      1. Most Relevant- Displays messages that best match your search keywords.
      2. Newest: Shows the most recently sent messages first.
      3. Oldest: Displays the earliest sent messages first.
    * After selecting a sort option, you can refine further using:
      1. **From** – Select and view messages shared by a specific user.
      2. **In** – Select and view the channels where the message was sent.
    * Tap **Apply** to view the sorted results and select the desired search result to open the conversation directly in the chat window.
