# Shifts

Shift management involves planning, tracking, and managing users' shifts. With Zuper, you can easily view user shifts, plan and schedule new ones, and track existing ones in real-time.

<Frame>
  **Navigation:** *Timesheets* --> *Shifts*
</Frame>

## Viewing user shifts

1. Select the "**Timesheets**" icon from the left navigation menu and choose "**Shifts**."

<img src="https://mintcdn.com/zuperinc/0hbDl4NBbErqwot_/Timesheets_Management/Timelogs/S1.jpg?fit=max&auto=format&n=0hbDl4NBbErqwot_&q=85&s=41eb07c66d561504cde56d5fc67245fb" alt="S1 Jp" width="1917" height="796" data-path="Timesheets_Management/Timelogs/S1.jpg" />

2. You can view all the users and their shifts based on the team, date range, and filter applied.

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S2.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=ac45418063b57a9c6a918fc9d01b3f50" alt="S2 Jp" width="1917" height="826" data-path="S2.jpg" />

3. Select the user's shifts link on the left to view a specific user's shifts.

<img src="https://mintcdn.com/zuperinc/0hbDl4NBbErqwot_/Timesheets_Management/Timelogs/S3.jpg?fit=max&auto=format&n=0hbDl4NBbErqwot_&q=85&s=636f533cdd7c4c5106644bb32ef2df66" alt="S3 Jp" width="1917" height="826" data-path="Timesheets_Management/Timelogs/S3.jpg" />

4. Once you have selected the user's shift link, you can view their scheduled shifts, including dates and times.

<img src="https://mintcdn.com/zuperinc/0hbDl4NBbErqwot_/Timesheets_Management/Timelogs/S4.jpg?fit=max&auto=format&n=0hbDl4NBbErqwot_&q=85&s=178878eda52f2077b1fe408c49a24d1f" alt="S4 Jp" width="1917" height="826" data-path="Timesheets_Management/Timelogs/S4.jpg" />

5. You can also customize the calendar view in Zuper to suit your needs better:

* **Month View**: This feature provides an overview of all users' shifts within a specific month, giving you a broad perspective on scheduling.
* **Week View**: Provides an overview of users' shifts each week, allowing for more granular planning and management.

## Update user shift

You can update a user shift in Zuper through any of the following ways:

* **Directly from the shifts page**
* **Selecting the user's shifts link from the left panel**

### Directly from the shifts page:

1. After landing on the Shifts page, you can view the user's shifts based on the team and date range selected.

<img src="https://mintcdn.com/zuperinc/0hbDl4NBbErqwot_/Timesheets_Management/Timelogs/S6.jpg?fit=max&auto=format&n=0hbDl4NBbErqwot_&q=85&s=35015d64835ae0517e0684323f356a83" alt="S6 Jp" width="1917" height="824" data-path="Timesheets_Management/Timelogs/S6.jpg" />

2. Hover over the user shift you wish to edit, where you'll see a pencil icon. Click the "**pencil icon**" to edit the shift details.

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S7.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=20f8f899241544e7d3fa4abf1c04931e" alt="S7 Jp" width="1917" height="826" data-path="S7.jpg" />

3. Once the necessary changes are made, click the "**Update**" button to save the changes.

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S8.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=72125da654bfb4efbb875db21c6e3780" alt="S8 Jp" width="1917" height="824" data-path="S8.jpg" />

<Note>
  **Note:** You can only edit the shift label and time, not the date. You can delete the user shift from here by clicking the Delete button.
</Note>

### Selecting User's shifts link from the left panel:

1. After landing on the shifts page, you can view the users and the number of shifts on the left.

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S9.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=17de2946e808a1a88b30eb25ec04ead0" alt="S9 Jp" width="1917" height="826" data-path="S9.jpg" />

2. Select the user's number of shifts.

<img src="https://mintcdn.com/zuperinc/UzQXhsiJl1KJlGVR/S10.jpg?fit=max&auto=format&n=UzQXhsiJl1KJlGVR&q=85&s=ffdadce2c15eeda3766544746ea14d30" alt="S10 Jp" width="1917" height="826" data-path="S10.jpg" />

3. You can view their scheduled shifts, including dates and times. Select a shift and use the edit and delete icons under the Action column to edit or delete it.

   <img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S11.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=5943f38545b145affcd6b0289fe4c4bb" alt="S11 Jp" width="1917" height="826" data-path="S11.jpg" />

## Adding a new shift

To add a new shift for a user in Zuper, follow these steps:

1. Click the "**Timesheets**" module from the left navigation menu and select "**Shifts**."

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S12.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=ae894bc9c15e741a7749d2dde6d52957" alt="S12 Jp" width="1917" height="796" data-path="S12.jpg" />

2. You can view all the users and their shifts based on the team, date range, and filter applied.

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S13.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=fa4b4fcd99a16abffa4e333567a73bb8" alt="S13 Jp" width="1917" height="826" data-path="S13.jpg" />

3. To create a new shift, click "**+ New User Shift**" at the top right corner of the page. A pop-up appears to create a new User Shift.

<img src="https://mintcdn.com/zuperinc/4-Los4YX_ob2IgRN/S14.jpg?fit=max&auto=format&n=4-Los4YX_ob2IgRN&q=85&s=94302d3fc41662cb2b634ad76f1cd335" alt="S14 Jp" width="1917" height="826" data-path="S14.jpg" />

4. Enter the following mandatory details in the pop-up and click the "**Create**" button.

* **User\***: Select the user for whom you are creating the shift.
* **Choose shift\***: Select the appropriate shift from the list.

<img src="https://mintcdn.com/zuperinc/0hbDl4NBbErqwot_/Timesheets_Management/Timelogs/S15.jpg?fit=max&auto=format&n=0hbDl4NBbErqwot_&q=85&s=3f4589334940224f1e90f349e479621a" alt="S15 Jp" width="1917" height="826" data-path="Timesheets_Management/Timelogs/S15.jpg" />

<Note>
  Note: Only shifts configured in Master Shifts under Timesheet Settings will be available here.
</Note>

* **Shift Start Date\***: Choose the date when the shift begins.
* **Shift End Date\***: Choose the date when the shift ends.

<Tip>
  The symbol (\*) indicates a mandatory field
</Tip>

5. The new shift will be added to the user's schedule, and they will be notified accordingly.

Following these steps, you can efficiently manage shifts and maintain smooth operational workflows within the Zuper platform.
