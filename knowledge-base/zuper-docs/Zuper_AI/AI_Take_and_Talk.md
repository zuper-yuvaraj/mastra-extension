# AI Take and Talk

> Powered by AI, this feature allows users to capture a photo and add a voice description that’s instantly transcribed and tagged with the image.

Zuper’s mobile app now features a new “**Take and Talk**” mode within the photo option in the Notes section. This functionality allows users to **capture a photo and immediately** **provide a description using voice input,** which is automatically **transcribed and saved along with the image**, making it tagged to the picture taken. This ensures that both visual and contextual details are captured in one seamless step.

<Note>
  **Note:** This feature is available only on select Zuper plans. To enable it for your account, please contact your account administrator or email us at [support@zuper.co](mailto:support@zuper.co)
</Note>

While this feature improves job site documentation by making it faster, easier, and more accurate, it also offers significant advantages for field technicians:

* **Increased efficiency**: Technicians can use it when multiple pictures need to be taken, and context needs to be added for each picture in real time without needing to stop and type.
* **Better accuracy**: Voice descriptions are transcribed instantly, reducing the risk of missing or unclear information.
* **Hands-free convenience**: Ideal for use in environments where technicians are wearing gloves or working hands-on.
* **Enhanced clarity for office teams**: Photos paired with transcribed context provide better visibility for the back office or supervisors when reviewing, quoting, or approving work.

This step-by-step instruction will guide you through using the “**Take and Talk**” mode in the Zuper mobile app:

## How to Use Take and Talk Mode

To use this feature in the Zuper mobile app, follow these steps:

1. Open the Zuper mobile app.
2. Navigate to the job where you want to add a note.
3. Tap the **Add note** tab within the job details screen. The camera will open automatically.
4. Tap the **Photo** section and activate **Take and Talk mode** by tapping the icon at the top right of the photo section.

<img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt1.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=f853b02c7da93144e0bcfc372434042c" data-path="images/tt1.png" />

5. Once **Take and Talk mode is active**, capture a clear photo of the subject (e.g., completed work, issue, or equipment).
6. After taking the photo, you’ll be immediately prompted to begin speaking. Your voice input will be automatically transcribed and tagged as a description of the image.

<img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt2.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=6d9b07da61a0d8c712142b5e57e00f21" data-path="images/tt2.png" />

7. Tap the <Icon icon="check" color="#040404" /> (tick) icon to proceed.

<img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt3.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=2c2736e347d2746c62eec5998d57f1ef" data-path="images/tt3.png" />

8. Review the description tagged to the captured image, then click **Attach** to add the image with its description to the note.

<img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt4.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=1eeab27d271f451b19984afd9e82ca4d" data-path="images/tt4.png" />

9. Click **Submit** to save the note.

<img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt5.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=4bc838e758288c46641e7d7540c32c05" data-path="images/tt5.png" />

### **Edit Description**

You can edit the description either before or after saving it using the **microphone input** or **manual editing** options.

<Tabs>
  <Tab title="To Edit Before Saving">
    To edit the description before saving, **tap the transcribed text** tagged to the image during the review step.

    <img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt10.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=1e8497e294fcb8ca94078b561c1e63c3" data-path="images/tt10.png" />

    You have two editing options:

    * **Microphone Input**\
      Tap the microphone icon to add additional voice input. The new input will be transcribed and automatically appended to the existing description.
    * **Manual Editing**\
      Tap inside the text field to manually modify the transcribed content using the on-screen keyboard. You can correct, add, or remove text as needed.

    <img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt7.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=498aa900d9a6aaf7a825f69ffc6be224" data-path="images/tt7.png" />
  </Tab>

  <Tab title="To Edit After Saving">
    If you need to make changes after the note has been saved:

    1. On the **Add Note** page, locate the note you want to edit.
    2. Tap the <Icon icon="ellipsis-vertical" color="#0d0d0d" />(Kebab icon) on the image.
    3. Select **Edit** from the menu.

    <img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt6.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=d4c1cdd9bf7ed122b383842cd51a6929" data-path="images/tt6.png" />

    4. Make the necessary changes using **microphone input** or **manual editing** options, then click **Add** to update the note.

    <img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt8.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=aaf0669b46dba6da51f53e8db348ca0d" data-path="images/tt8.png" />
  </Tab>
</Tabs>

### **Refine Description with AI Capabilities**

Zuper also offers AI-powered tools to further enhance your notes. These features help improve clarity, correctness, and accessibility:

<img width="250" height="200" src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/tt9.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=e308f91922d6fd37eb87bb7565350f91" data-path="images/tt9.png" />

* **Summarize**\
  Condenses long descriptions into a clear, concise summary, making notes easier to read and understand.
* **Clean Up**\
  Automatically corrects grammar, spelling, punctuation, and sentence structure for professional, polished content.
* **Translate**\
  Instantly translates notes into any of 17 supported languages, including Dutch, French, Slovenian, and Spanish—broadening accessibility for global teams.
