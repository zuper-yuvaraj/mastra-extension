# Adding new property

Adding a property allows you to define the exact physical location where services need to be delivered. A property may represent a customer’s office, retail store, or residence and includes vital information like the address, contact person, and service history. Setting up properties ensures accurate job scheduling, technician dispatching, and record-keeping, especially when a customer has multiple service locations.

<Frame>
  **Navigation**:  Clients  -> *Properties  ->+ New Property* 
</Frame>

1. Select the "**Clients**" module from the left navigation menu and choose **Properties**. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property1.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=6523ac02a504b34da8fa8a11ef778988" alt="Property1 Pn" width="1914" height="868" data-path="Client/Property/Property1.png" />
2. The **Properties** listing page opens.
3. Click the "**+ New Property**" button at the top right corner of the page. A new property creation page will appear. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property2.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=0b815a825b6c98437aa0497ab7f1f0e3" alt="Property2 Pn" width="1912" height="866" data-path="Client/Property/Property2.png" />
4. Fill in the following sub-sections:
   1. **Primary Details**
      * **Choose Organization**: Select the organization that this property belongs to.
      * **Property Name**: Enter the name of the property.
      * **Property Image**: Upload an image to visually identify the property.
      * **Choose Parent Property**: If this property is a child property, choose a parent property.
      * **Pricelist**: Select the relevant price list to be applied when jobs or services are performed for this property. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property3.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=940bf434bf989d3936993ec83dd26b76" alt="Property3 Pn" width="1906" height="670" data-path="Client/Property/Property3.png" />
   2. **Tax Details** Choose the applicable tax settings for the property based on your region or internal policies. These settings will automatically be applied to invoices and billing documents. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property4.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=4ed4d72c7c6f15b20a82fdec30d4ff64" alt="Property4 Pn" width="1891" height="896" data-path="Client/Property/Property4.png" />
   3. **Property Address** Add the property locations. You can specify these details in two ways.
      * **Address Entry**: Type the full physical address.
      * **Geo-Coordinates**: Enter latitude and longitude if you want to use exact map-based positioning. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property5.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=47bb61a945cb3d4b25709acba9106ff1" alt="Property5 Pn" width="1901" height="699" data-path="Client/Property/Property5.png" />
        <Tip>
          For the most accurate location data, use the **"Pick from Map"** option. This allows you to pinpoint the address directly on the map interface.\
          \
          Once you've selected the correct location, click "**Use this Address**" to save the information. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property6.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=cafb7670f1fa48604a69e1fc090c2b5b" alt="Property6 Pn" width="1903" height="816" data-path="Client/Property/Property6.png" />
        </Tip>
   4. **Contacts**: Add customer information for this property. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property7.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=b4a76bb96b66f75471598865fdc1bbd1" alt="Property7 Pn" width="1902" height="761" data-path="Client/Property/Property7.png" />
   5. **Other Details** If any custom fields are added under the settings, you can fill in the details.
   6. **Save Property** After entering all the necessary details, click the "**Save Property**" button to successfully create the property. <img src="https://mintcdn.com/zuperinc/REyxl-NZWG7jHng2/Client/Property/Property8.png?fit=max&auto=format&n=REyxl-NZWG7jHng2&q=85&s=82ded833d363a4dd2ebb6d8a384b8707" alt="Property8 Pn" width="1909" height="897" data-path="Client/Property/Property8.png" />

### Address sync with customer/contacts

If this property is linked to a contact, Zuper keeps the addresses on both records in sync. Update the address here, and Zuper updates the service address on the linked contact automatically and vice versa.

Creating a property is essential for associating it with multiple modules, such as assets and contacts. This association enables field technicians to efficiently provide services to end contacts.
