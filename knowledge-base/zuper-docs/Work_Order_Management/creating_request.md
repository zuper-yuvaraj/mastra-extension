# Creating a new request

The Zuper Web App's request module enables administrators (back-office Admins) and contacts to create and manage service requests.

For instance, when a portal is enabled for a contact, the contact can submit and view the requested services within a portal. Meanwhile, if the contact requests a service via email, phone call, website, or social media, then the admin from the back-office team will create the request on behalf of the
contact and convert it to a job/quote. This, in turn, helps businesses streamline service requests, enhancing efficiency.

However, to use the request module efficiently, it is important to configure request settings. After configuring the request settings based on your business, follow these steps to create a request.

## Creating a new request

<Frame>
  **Navigation:** *Request--> Request Listing page--> +New Request*
</Frame>

1. Select the “**Request**” module from the left navigation menu. The requests listing page displays all the requests raised by the contacts.  Click the “**+ New Request**” button on the top right corner to create a new request.

<img src="https://mintcdn.com/zuperinc/UzQXhsiJl1KJlGVR/Req1.jpg?fit=max&auto=format&n=UzQXhsiJl1KJlGVR&q=85&s=ddf29b10d5ababcca3ec4ca5c5399691" alt="" width="1913" height="864" data-path="Req1.jpg" />

2. Choose the service the contact requests and click the “**Choose Service**” button to confirm it (these services appear based on the configuration you set in the request settings).

The unit price will be auto-filled once the service has been chosen. Enter the request details, such as the “**Request title**” and “**Description**.”

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation1.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=64b65779850cac8de8a347897f364d33" alt="" width="1905" height="878" data-path="Work_Order_Management/Jobs/Reqcreation1.png" />

3. Choose the contact’s preferred dates and time slots to perform the request.

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation2.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=19a509a18e0d16615e36cdc69525310a" alt="" width="1915" height="868" data-path="Work_Order_Management/Jobs/Reqcreation2.png" />

4. Select the request's due date, source, and priority.

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation3.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=cc08bd80664c6dedcefb3d5a88d277be" alt="" width="1901" height="860" data-path="Work_Order_Management/Jobs/Reqcreation3.png" />

5. Once done, providing the contact/organization details is mandatory to save the request, then click "**Add Organization/ Add Contact**."

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation4.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=6390c3d2ffb1537c2044cb5c25003ccd" alt="" width="1906" height="872" data-path="Work_Order_Management/Jobs/Reqcreation4.png" />

<Note>
  **Note:** You can choose either an organization or a contact.
</Note>

6. Choose the organization/contact from the list and click the “**Save Request**” button.

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation5.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=53d4904fdb5e052e5bfa3687bd0495f9" alt="" width="1887" height="868" data-path="Work_Order_Management/Jobs/Reqcreation5.png" />

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation6.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=00efcfc6b56abaf75f4bc3de08651576" alt="" width="1883" height="882" data-path="Work_Order_Management/Jobs/Reqcreation6.png" />

7. The request is created successfully, and then you can convert it to a job/quote based on its nature. Additionally, you can track and update the request's status from here.

<img src="https://mintcdn.com/zuperinc/oK11ni6ybXrWMAjU/Work_Order_Management/Jobs/Reqcreation7.png?fit=max&auto=format&n=oK11ni6ybXrWMAjU&q=85&s=4a34a16fd5acb6700d2d169d0947696e" alt="" width="1876" height="825" data-path="Work_Order_Management/Jobs/Reqcreation7.png" />
