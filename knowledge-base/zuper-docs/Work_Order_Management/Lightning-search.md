# Lightning Search

**Zuper Lightning Search** is a fast search tool that helps you quickly find records such as Jobs, Contacts, Quotes, Invoices, Properties, and Products from a single search bar. It searches the entire platform and displays results instantly, letting you preview items or open the full search results page for more details.

<Note>
  **Note**: This feature is currently in Beta, and please contact the account manager to get access.
</Note>

<Info>
  **Global Search, Lightning Search, and Atlas Search**

  * By default, Zuper uses **Global Search** — the standard search available to all users.
  * **Lightning Search** is an enhanced search experience that delivers faster results and    broader cross-module coverage.
  * **Atlas Search** offers an additional layer of search    capability built on advanced indexing technology.
  * Both Lightning Search and Atlas Search are available as upgrades to Global Search. To switch, contact [Zuper Support](mailto:support@zuper.co).
</Info>

## **Filter Search by Module**

Click the **filter icon** (top-right of the search window). A dropdown appears where you can check/uncheck categories:

* Jobs
* Contacts
* Quotes
* Invoices
* Properties
* Products

Only selected modules will appear in the results. This is great for narrowing down large searches.

## **View full search results**

To see everything in a clean table view:

* **“View all →”** link at the top or
* Press **Enter** while typing.
* **↑ ↓** arrows → Move up/down the list.
* **Enter** → Open the selected record.
* **Esc** → Close the window completely.
