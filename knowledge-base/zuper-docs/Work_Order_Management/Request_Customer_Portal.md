# Using with Customer Portal

Customers can submit and view their requested services through the portal. There are various channels to contact the business for service requests, including the customer portal, email, phone calls, the website, social media, and more.

\
Select the "**Requests**" module from the left panel to access service requests. This module includes the following sections:

## Request Listing Page

* The Request Listing Page summarizes job requests in a list format.

i. **Filter by Category**
You can filter requests based on a preferred category using the drop-down menu.

You can filter requests based on their planned dates using the drop-down menu.

## Request Details Page

* The Request Details Page provides in-depth information about a selected request.

To view request details:

Select the "**Request**" module from the left panel. Choose the specific request you want to examine in detail.

\
Creating a New Request\
Navigate to the "**Request**" module from the left panel. All customer requests will be displayed on the Request Listing Page.\
Click the "**New Request**" button in the top-right corner to create a new request.

<img src="https://mintcdn.com/zuperinc/6cbFCQfQfzHSjJuY/Work_Order_Management/CPO4.jpeg?fit=max&auto=format&n=6cbFCQfQfzHSjJuY&q=85&s=3ff08c14c145add97160e7bedb11ebd9" alt="/Work_Order_Management/CPO4.jpeg+_existingInIndexedDbMintlify" width="1656" height="762" data-path="Work_Order_Management/CPO4.jpeg" />
