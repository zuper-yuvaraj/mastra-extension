# Notes and chats

### Notes

The **Notes** and **Chats** sections on a job record keep your team aligned without switching to another tool. Use **Notes** to record field observations, maintenance summaries, safety instructions, or follow-up actions — all stored alongside the job for full context and traceability. Use **Chats** to send real-time messages between back-office staff and field technicians.

Notes support rich text formatting, voice-to-text input, file attachments, linked records, and privacy controls. This article covers every feature of the Notes and Chats experience.

## Accessing notes on a Job 

1. Click “**Notes**” on the left panel to add the notes. You can use the rich text editor to enter the note details.

2. Click the '**Enter your notes here**...' text field at the top of the Notes area and add the Notes. This opens the New Note editor dialog.

<Accordion title="Available Content Types">
  Click the "**+**" button to choose the available content types:

  **Text**

  Inserts a standard paragraph block. Use this for general descriptions, instructions, or any freeform content.

  **Heading**

  Inserts a large heading block. Useful for organizing notes with clear section titles (e.g., 'Maintenance', 'Findings', 'Next Steps').

  **Unordered List**

  Inserts a bulleted list. Use this for items that don't need a specific order — such as a list of parts checked or observations made.

  **Ordered List**

  Inserts a numbered list. Use this for step-by-step instructions or prioritized action items.

  **Checklist**

  Inserts a checklist with checkboxes. Ideal for to-do items, pre-service checklists, or task tracking within a note.

  **Table**

  Inserts a structured table. Use this to organize data in rows and columns, such as measurements, equipment specs, or comparison data.

## Block-Level actions (convert, move, delete)

Once a content block has been added, hover over it to reveal two action icons on the right:

**Adds a new block immediately after this one** — + (Plus icon)

**Opens a context menu with the following actions** — (Drag/Options icon)

* **Convert to** — Changes the block type (e.g., from Text to Heading, or from Unordered List to Checklist). A submenu shows the available target types.
* **Move up** — Moves the current block one position up in the note.
* **Delete** — Removes the block from the note.
* **Move down** — Moves the current block one position down in the note.

## Inline text formatting

When you select text within any block, a formatting toolbar appears with the following options:

* B — Bold
* I — Italic
* U — Underline
* S — Strikethrough
* Link icon — Insert a hyperlink
* Unordered list toggle
* Ordered list toggle

These options let you style individual words or phrases within a block, independent of the block type.

### Use voice-to-text

The note editor includes a built-in voice-to-text feature. Select the microphone icon in the editor toolbar to dictate your note hands-free. This is useful for field technicians who cannot type while on site.

<Note>
  Your device might prompt you to grant microphone permission the first time you use voice-to-text. Select **Allow** to proceed.
</Note>

<Frame>
  <img src="https://mintcdn.com/zuperinc/kOr1Z83r9mcs3Ddg/images/Notesnew11.png?fit=max&auto=format&n=kOr1Z83r9mcs3Ddg&q=85&s=35ce5aaf021dab84823bce221a22a6ea" alt="Notesnew11" width="1920" height="878" data-path="images/Notesnew11.png" />

* You can attach supporting files directly to a note before posting it.

A file picker dialog will open. The following constraints apply:

* Maximum 5 attachments per note
* Maximum 20 MB per file
* Supported file types: Images, Videos, Audio, PDF, Docs, Excel, Archives, and other Files

    ### Replying to a note

    Every reply stays attached to the original note, so the conversation never loses its context within the job. Reply visibility follows the privacy setting of the parent note.

## Pin notes

Pinned notes are displayed at the top of the Notes list, regardless of sort order. This is useful for keeping critical information, such as access instructions or safety notices, always visible.

To pin a note, click the three-dot (⋮) menu on the posted note and select Pin Note. To unpin, click the same menu and select Unpin Note.

  <img src="https://mintcdn.com/zuperinc/kOr1Z83r9mcs3Ddg/images/Notesnew14.png?fit=max&auto=format&n=kOr1Z83r9mcs3Ddg&q=85&s=48c0479fd1a065218191f8ecc1e9fb7f" alt="Notesnew14" width="1920" height="878" data-path="images/Notesnew14.png" />

You can control whether you receive notifications for activity on a note before posting it.

Click the bell icon in the bottom toolbar of the note editor to toggle notifications on or off. When enabled, you will receive notifications when others reply to or update the note.

<Frame>
  <img src="https://mintcdn.com/zuperinc/kOr1Z83r9mcs3Ddg/images/Notesnew15.png?fit=max&auto=format&n=kOr1Z83r9mcs3Ddg&q=85&s=c70e2dda7e12db63996638e338f6bce6" alt="Notesnew15" width="1920" height="878" data-path="images/Notesnew15.png" />
</Frame>

Once you have finished composing your note and configuring any attachments, links, or notification preferences, click the Post Note button.

<Note>
  **Web vs. mobile:** On the web app, new notifications appear in the notification area. On the Zuper mobile app, notifications arrive as push notifications on your device. Enable push notifications in your device settings to receive them.
</Note>

The note will be saved and appear in the All Notes list under the job, along with the author's name, timestamp, and note content.

## Privacy

* Control who can see the note. Three privacy levels are available:
  | Visibility Option | Description |
  | :- | :- |
  | Public | Visible to all users with access to the job |
  | Only Me | Visible only to the note author |
  | Backoffice Only | Visible only to internal back-office users, not field technicians |

## Chats

The **Chats** section enables real-time messaging between back-office staff and field technicians — all within the job record, without leaving Zuper.

You can send text messages and attach files such as images or documents directly in the chat.

<Note>
  **Web vs. mobile:** On the web app, new chat messages appear as a notification. On the Zuper mobile app, chat messages arrive as push notifications. Enable push notifications in your device settings to receive mobile alerts.
</Note>

<Info>
  An enhanced chat experience is available for customers on the **Premium plan**. To learn more, see the [Chat quickstart guide](https://docs.zuper.co/Chat/quickstart-guide).
</Info>
