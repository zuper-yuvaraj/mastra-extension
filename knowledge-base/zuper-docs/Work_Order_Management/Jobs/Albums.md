# Albums

## Overview

Welcome to Zuper's new **Gallery Album** feature! Albums are automatically created as defaults for new jobs; however, you can customize them to fit your scenario.\
Whether you're capturing site inspections or progress updates, Gallery Albums keep everything structured and accessible. This article covers setup, daily use, sharing, and management—let's get started!

<Frame>
  **Navigation**: *Settings -->  Modules --> Jobs --> Gallery Settings*
</Frame>

## **Setting up default albums for jobs**

To ensure consistency across all jobs, configure default albums in your workspace settings. These will auto-populate when you create a new job.

### **Steps to manage default albums:**

1. From the left navigation menu, Select Settings and under Modules > **Job Settings** > **Gallery Settings**.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album1.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=37db618ba3f2c0a6b100147ff7550972" alt="Album1 Pn" width="1920" height="878" data-path="images/Album1.png" />

2. Click "**+ Add Album**" to add the new album.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album21.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=c8c0d1e1498d3ee871e5220dca6e9472" alt="Album21 Pn" width="1920" height="878" data-path="images/Album21.png" />

3. In the **Albums** section, you will see a list of pre-built default albums:

* **Adjuster**
* **Build**
* **Completion Photo**
* **Crew**
* **Homeowner**
* **Inspection**

<Note>
  **Note**: For the Roofing industry, default albums are available, and new albums can also be created. For other industries, you need to create new albums.
</Note>

4. Edit or delete existing albums using the icons next to each one (pencil for editing, trash for delete).
   <Note>
     Note: Deleting a default album removes it from new jobs but won't affect existing ones.
   </Note>

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album17.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=a72228af2e3956cbf0889530904bf0c2" alt="Album17 Pn" width="1920" height="878" data-path="images/Album17.png" />

<Tip>
  **Tip**: Use descriptive names to match your job stages. Albums sync across teams for seamless collaboration.
</Tip>

## **Working with albums in a job**

**Navigation**: Jobs -->  Job --> Gallery --> Albums

Once a job is created, albums appear in the **Gallery** tab for easy photo management.

### **Accessing Albums in a Job:**

1. Open the job from the **Jobs** list.
2. Click the **Gallery** icon in the left navigation.
3. You'll see your default albums as folders after clicking the “**Albums**” tab.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album20.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=f07812cbdd9d31707080b5a505b64d1b" alt="Album20 Pn" width="1911" height="868" data-path="images/Album20.png" />

4. Select an album before uploading and add images from the Job gallery / from the device. Click "**Add to Album**" to confirm.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album19.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=e2117b2323976977ada51c1326161d67" alt="Album19 Pn" width="1920" height="878" data-path="images/Album19.png" />

## **Managing individual albums**

Customize albums per job without affecting defaults. Right-click (or use the three-dot menu) on an album folder for options.

### **Sharing albums securely**

Share albums via email (or text for Zuper Connect users) to keep stakeholders updated without overwhelming them with attachments. Shared links offer view-only access with customizable expiration dates. After sharing, track and manage active shares directly in the Gallery.

**Steps to share an album:**

1. In the job's Gallery, right-click the album > **Share**.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album4.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=e2d1c4e16b75e3dfaa4f2c1ce8e180e5" alt="Album4 Pn" width="1910" height="872" data-path="images/Album4.png" />

2. In the **Share Album** dialog box:

* **Select Method**: Choose **Email** (default) or **Text Message** (Zuper Connect exclusive).

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album8.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=ec34b2458669bfbb9ce3c604c64582ac" alt="Album8 Pn" width="1920" height="878" data-path="images/Album8.png" />

3. **Enter Details**:

* Email Address: Add recipient(s). The customer's email ID will be shown for easy selection/typing of any email address if it is not the primary email contact.
* Subject: Enter the subject of the Album.
* Email Body: Customize the message.

CC/BCC: Add extras if needed.

4.**Access Expiry** : Set how long the link lasts:

* 7 Days
* 30 Days
* 90 Days
* Never Expires

5. Custom Date Recipients get a notification on the expiry date.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album9.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=c0a4241d9af68b362bc43264cfcd277e" alt="Album9 Pn" width="1920" height="878" data-path="images/Album9.png" />

6. Click **Share Album** to send.

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album10.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=8240a6b1a0897a7a50d1d4898afd7dc4" alt="Album10 Pn" width="1920" height="878" data-path="images/Album10.png" />

7. You will see a message: "**Album shared successfully**."

<img src="https://mintcdn.com/zuperinc/McZHqLcpEJrb8tP6/images/Album11.png?fit=max&auto=format&n=McZHqLcpEJrb8tP6&q=85&s=561cdae8bc67d2b66408c88961af01dd" alt="Album11 Pn" width="1920" height="878" data-path="images/Album11.png" />

## **Text message sharing (Zuper Connect only):**

* Select **Text Message** instead of Email.
* Enter phone number(s) and a brief message.
* **Note**: For details on Zuper Connect setup, contact [support@zuper.co](mailto:support@zuper.co).

**Security Note**: Shares are view-only and can be revoked at any time via the Manage Shares feature. Non-Zuper users get a secure, branded link.

| **Sharing Option** | **Availability** | **Key Features** |
| :- | :- | :- |
| Email | All Users | Custom body, CC/BCC, expiry options; track via Manage Shares |
| Text Message\* | Zuper Connect | Quick SMS links, phone-based; exclusive to Connect users |

**\*Text Message is applicable only for Zuper Connect users.**

<Note>
  Note: Text message sharing requires Zuper Connect. To learn more about how to set it up, see Zuper Connect overview. Contact [Zuper Support](support@zuper.co) if you need help getting started.
</Note>

## **Best Practices and Troubleshooting**

* **Organize Early**: Assign photos to albums during the job to avoid last-minute sorting.
* **Team Collaboration**: Assigned users/teams (e.g., Monica Klein) can view and add to albums in real-time.
* **Common Issues**:
  * **Can't Share?** Ensure the recipient's email is valid; text is limited to Zuper Connect.
  * **Expiry Passed?** Reshare with a new link or edit via Manage Shares.
  * **No Albums Visible?** Check Job Settings > Gallery Settings for the default settings.
  * **Delete Warning Ignored?** Remember, items stay in the gallery; Use "**All photos**" to recover.

Zuper's Gallery Album revolutionizes roofing teams' job photo management, streamlining organization, fostering collaboration, and enabling secure admin-only access that builds trust with clients and stakeholders. Leverage default albums for consistency and per-job customizations for flexibility to save time on documentation while keeping every visual detail readily available.
