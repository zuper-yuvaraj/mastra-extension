# Zendesk Support

The Zendesk-Zuper integration helps the user connect the Zendesk support tickets with Zuper. The bi-directional data flow based on the settings allows the user to update the ticket details on both Zendesk and Zuper.

We are going to see two different setups:

**Zendesk – Zuper Integration**

**Zuper – Zendesk Integration**

## Pre-Requisites:

API Keys. Click [here](https://docs.zuper.co/Settings/Developer_Hub/API_Keys#api-keys) to know how to create and use API keys

**What Happens After Authorization**

After successful authorization:

* Map Zuper jobs to Zendesk tickets.
* Automatically update ticket custom fields with job status, assigned technician, scheduled date, and customer signatures.
* Job notes sync as Zendesk ticket comments, including any attachments.
* Tickets can automatically resolve or close based on mapped job statuses.

**Best Practices**

* Authorize the integration using a Zendesk admin account to avoid permission issues.
* Configure the required Zendesk custom fields for job mapping before connecting.
* Do not disconnect the OAuth authorization unless you need to reset the integration.

## D. How does Job creation work in Zendesk?

1. From the right panel of Zendesk, Choose “**Create Job**” to create a new job. You need to fill the following tabs :

**Customer Details Tab** - Enter the client’s details.

\*\*Job Details Tab \*\*- Enter the work order details.

**Assign Employees** - Assign the field technicians using assisted scheduling option.

2. Asset Picker helps you to select the resources from Zuper’s Jobs module of Zendesk.

<img src="https://mintcdn.com/zuperinc/19_UW2yMUVV3uouV/images/Zen19.png?fit=max&auto=format&n=19_UW2yMUVV3uouV&q=85&s=da3684bc12a5258ac5d7781028e53ce2" alt="Zen19 Pn" width="1920" height="939" data-path="images/Zen19.png" />

3. Parts Picker helps you select the parts from the Zuper’s Jobs module of Zendesk.

<img src="https://mintcdn.com/zuperinc/19_UW2yMUVV3uouV/images/Zen20.png?fit=max&auto=format&n=19_UW2yMUVV3uouV&q=85&s=07a4e4061ce02b2d9ecc5b19dca3918b" alt="Zen20 Pn" width="1905" height="939" data-path="images/Zen20.png" />

4. Contract Picker helps you select the agreements from Zuper’s Jobs module of Zendesk.

<img src="https://mintcdn.com/zuperinc/19_UW2yMUVV3uouV/images/Zen21.png?fit=max&auto=format&n=19_UW2yMUVV3uouV&q=85&s=a76a60a5dff9160a99b27e555ffd58c1" alt="Zen21 Pn" width="1905" height="939" data-path="images/Zen21.png" />
