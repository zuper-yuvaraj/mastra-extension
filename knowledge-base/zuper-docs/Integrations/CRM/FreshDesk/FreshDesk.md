# FreshDesk

With Zuper’s first-class integration with Freshdesk, it seamlessly helps push Freshdesk tickets to Zuper, delivering an exceptional customer experience. You can create a Job from a Freshdesk ticket with a bi-directional sync.

The three major sections we are going to discuss here are:

A. How to connect Zuper with Freshdesk?

B. How to connect Freshdesk with Zuper?

C. How does Zuper –Freshdesk Integration work?

D. How to uninstall Freshdesk from Zuper?

**A. How to connect your Zuper with Freshdesk?**

1. Open a new tab in your browser once you are logged in to your Freshdesk, and select the Freshdesk **App Store**.

a. **Zuper Region** (Mandatory) – Enter the region of Zuper for which Freshdesk integration is applicable.

b. **Zuper API Key** (Mandatory) - To create the Zuper API key, Click [**here**](https://docs.zuper.co/Settings/Developer_Hub/API_Keys#api-keys) to know how to create and use API keys

c. **Freshdesk Domain** (Mandatory) - Enter Freshdesk’s URL.

d. **Freshdesk API Key** (Mandatory) – Copy-paste the Freshdesk API key from your Freshdesk account (How to find your API key).

e. **Sync Notes Automatically** – You can choose either “**Yes**” or “**No**” to sync or unsync Zuper Job Notes with Freshdesk.

f. Choose Notes to Sync – You can choose the type of notes for which the sync should happen from Freshdesk to Zuper. Options available are **Private Note**, **Public Note**, and **Reply**.

g. Enable Full Page to Support Agent – You can choose either “**Yes**” or “**No**” to set permissions for the Support Agents to the Full Page app access within Freshdesk.

## B. How to connect your Freshdesk with Zuper?

1. Open a new tab in your browser once you are logged in to your Zuper Account. Click on your Profile Picture in the top right corner of the screen and select the “**App Store**.”

<img src="https://mintcdn.com/zuperinc/M4JqQ68bNxvkxTES/images/Zcrm1.png?fit=max&auto=format&n=M4JqQ68bNxvkxTES&q=85&s=5b5d74b7c119dfd939b2c0c99ec4289b" alt="Zcrm1 Pn" width="1903" height="872" data-path="images/Zcrm1.png" />

2. Under the “**Browse by Category**,” select the “**CRM**” option and choose “**Freshdesk**.”

<img src="https://mintcdn.com/zuperinc/oz3deuyqs2bjRahT/images/Fdesk3.png?fit=max&auto=format&n=oz3deuyqs2bjRahT&q=85&s=cb5639df9b79facf8b1f0a21a9038041" alt="Fdesk3 Pn" width="1920" height="881" data-path="images/Fdesk3.png" />

3. Click on the “**Install Freshdesk**” button.

<img src="https://mintcdn.com/zuperinc/oz3deuyqs2bjRahT/images/Fdesk4.png?fit=max&auto=format&n=oz3deuyqs2bjRahT&q=85&s=cb293b1adec06e3cdf5f84be4f0c1c42" alt="Fdesk4 Pn" width="1918" height="878" data-path="images/Fdesk4.png" />

4. Update Zuper Settings by configuring the following fields:

a. Zuper API Key (Mandatory) – To create the Zuper API key, Click [**here**](https://docs.zuper.co/Settings/Developer_Hub/API_Keys#api-keys) to know how to create and use API keys.

b. Freshdesk API Key (Mandatory) – Copy paste the Freshdesk API key from Freshdesk account ([How to find your API key](https://support.freshdesk.com/en/support/solutions/articles/215517-how-to-find-your-api-key)).

c. Freshdesk Subdomain (Mandatory) - Enter the Freshdesk Subdomain details here.

d. Sync Zuper Status Updates - You can choose either “**Yes**” or “**No**” to sync or unsync Zuper Status updates with Freshdesk.

e. Sync Zuper Custom Fields - You can choose either “**Yes**” or “**No**” to sync or unsync Zuper Custom Fields with Freshdesk.

f. Sync Zuper Job Notes - You can choose either “**Yes**” or “**No**” to sync or unsync Zuper Job Notes with Freshdesk.

g. Freshdesk Status Field Name - You need to enter the Freshdesk Field Name for which Zuper gets synced.

h. Freshdesk Assignees Field Name - You need to enter the Freshdesk Assignees Field Name for which Zuper gets synced.

i. Freshdesk Start Date Field Name - You need to enter the Freshdesk Start Date Field Name for which Zuper gets synced.

j. Freshdesk End Date Field Name - You need to enter the Freshdesk End Date Field Name for which Zuper gets synced.

k. Freshdesk Customer Signature Field Name - You need to enter the Customer Signature for which Zuper gets synced.

l. Freshdesk Ticket Close Statuses - You need to enter the list of Freshdesk Ticket Close Statuses for which Zuper status get synced (Use a comma separator to add multiple statuses).

m. Mark Freshdesk ticket as? - You need to choose the status of the Freshdesk ticket from the dropdown list - **None**, **Closed**, or **Resolved**.

<img src="https://mintcdn.com/zuperinc/oz3deuyqs2bjRahT/images/Fdesk5.png?fit=max&auto=format&n=oz3deuyqs2bjRahT&q=85&s=ed372a19e052421f0ce0e8cdf5036239" alt="Fdesk5 Pn" width="1917" height="1867" data-path="images/Fdesk5.png" />

Select the “**Update**” button to connect Freshdesk with Zuper.

### Custom fields

If custom field values you saved in Zuper are not appearing in Freshdesk, check the following:

1. Confirm **Sync Zuper Custom Fields** is set to **Yes** in your Freshdesk integration settings.
2. Check whether the Freshdesk ticket was already closed before you saved the custom fields in Zuper. If so, reopen the ticket in Freshdesk, then re-save the custom fields in Zuper to trigger the sync.
3. Confirm the field names match exactly in both systems. Only fields with identical names sync automatically.

If the issue continues, contact [Support](mailto:support@zuper.co).

### Workflow execution history

Check workflow execution history for errors

If a workflow linked to this integration is not running as expected, you can check its execution history to find where it failed.

1. Go to the **Jobs** module and open the relevant job.
2. In the right panel, locate **Workflow Activity** and select **View History**.
3. Review the **Status** column. Select any failed run to see the error message and the node where the failure occurred.
4. To retry a failed run, select the **Retry** icon next to the execution.
5. If you have resolved the issue manually, select **Acknowledge** to mark the run as reviewed.
