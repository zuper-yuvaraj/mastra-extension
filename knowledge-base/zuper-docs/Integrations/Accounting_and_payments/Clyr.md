# Clyr

The Zuper-Clyr integration automates expense management for field service businesses, combining Zuper’s job and customer management with Clyr’s AI-driven expense tracking. Key features include:

* **Expense Tracking**: Add credit card details in Clyr to automatically track expenses. Capture receipts via the Clyr mobile app, which sync as Parts & Services in Zuper jobs.
* **Job-to-Project Sync**: Zuper jobs sync as Clyr projects, enabling seamless expense association.
* **Customer-to-Client Sync**: Zuper customers sync as Clyr clients for consistent data.
* **User Sync**: Zuper users sync to Clyr, supporting role-based expense submission and approvals.
* **Cost Visibility**: Expenses mapped to Clyr projects appear in Zuper jobs, improving job costing and budget tracking.

This integration minimizes manual entry, ensures policy compliance, and boosts efficiency for mobile workforces (e.g., HVAC, plumbing).

## Integrate and Use Clyr with Zuper

To set up and use the integration, follow these steps.

1. On Zuper, select the “**Jobs**” module from the left navigation menu and create a new job by filling in the necessary details.

2. The new job is created successfully.

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr2.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=ffc3fe742fd340bac6ba0b20a7bff9d3" alt="Clyr2 Pn" width="1920" height="878" data-path="images/clyr2.png" />

3. On Clyr, click Projects in the left navigation menu. Choose the Zuper Job that is captured as a project.

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr3.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=b4b99e9a5b3a373f395919c2e8a042c8" alt="Clyr3 Pn" width="1161" height="501" data-path="images/clyr3.png" />

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr4.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=1cbcb758312aba31a79ad0a0f7abfdb3" alt="Clyr4 Pn" width="1169" height="541" data-path="images/clyr4.png" />

4. Select the Transactions module and choose the exact transaction for which the project needs to be assigned.

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr5.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=71b43ad020637f742dc69b1636fae72d" alt="Clyr5 Pn" width="1143" height="498" data-path="images/clyr5.png" />

5. Choose the project and map this to the transaction.

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr6.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=c6710e436b3fadf740287e5697668298" alt="Clyr6 Pn" width="1129" height="549" data-path="images/clyr6.png" />

6. The transaction is mapped to the project successfully.

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr7.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=a68a7a6bbc5b01cf0df9d07d94f4a59c" alt="Clyr7 Pn" width="1143" height="498" data-path="images/clyr7.png" />

7. Switch to Zuper. You can view the transactions under the parts and services section in the job.

<img src="https://mintcdn.com/zuperinc/J0BkQIM5OTY4C_JR/images/clyr8.png?fit=max&auto=format&n=J0BkQIM5OTY4C_JR&q=85&s=0c527cd6a03ffa32fbbb07849c2866d2" alt="Clyr8 Pn" width="1919" height="862" data-path="images/clyr8.png" />

<Note>
  **Note**: Users on Zuper are synced as users on Clyr. The customers on Zuper are synced as clients on Clyr.
</Note>
