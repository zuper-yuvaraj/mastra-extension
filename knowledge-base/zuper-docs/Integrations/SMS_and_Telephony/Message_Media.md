# Message Media

The **Zuper–Message Media integration** enables you to send outbound **Text Message/Text Notifications** to your contacts directly from Zuper using your Message Media account. This ensures customers receive instant updates on pending items, job progress, or service alerts.

<Note>
  Note:

  1. To enable the Message Media integration on your account, contact our Support Team at [support@zuper.co](mailto:support@zuper.co).
  2. Ensure that Text Message/Text Notifications are enabled for your contacts.

     Navigation: Contacts → Contacts Listing page → Edit (via three-dot icon) → Edit Contact page → Notification Preferences
  3. The Zuper–Message Media integration currently supports the following countries: Australia, Canada, New Zealand, the UK, and the US.
</Note>

## A. Connecting Message Media with Zuper

Follow the steps below to integrate your Message Media account with Zuper.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store** from the dropdown menu.

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk1.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=2bc9016867f229998cb6d6266d1787fd" alt="Cloudtalk1 Pn" width="1904" height="872" data-path="images/Cloudtalk1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **Message Media** from the list of available integrations. Click **Install Message Media**.

<img src="https://mintcdn.com/zuperinc/ZFbeTmwB9cv-vBym/images/Messagemedia1.png?fit=max&auto=format&n=ZFbeTmwB9cv-vBym&q=85&s=9d652cd06ceefaa8146cf4c1a556c3a7" alt="Messagemedia1 Pn" width="1265" height="606" data-path="images/Messagemedia1.png" />

<Tip>
  Tip: Keep both the Zuper and Message Media tabs open during setup to switch between them easily.

  ###
</Tip>

In the configuration window, fill in the following details:

| Field | Description |
| :- | :- |
| **Authentication Method (Mandatory)** | Select the authentication method – either **Basic Auth** or **HMAC**. |
| **Auth Username  (Mandatory)** | Enter your Message Media authentication username. |
| **Auth Password (Mandatory)** | Enter your Message Media authentication password. |
| **Enable SMS Notification** | Select **Yes** to enable Text Message notifications. |

<img src="https://mintcdn.com/zuperinc/ZFbeTmwB9cv-vBym/images/Messagemedia3.png?fit=max&auto=format&n=ZFbeTmwB9cv-vBym&q=85&s=08284d266d721239e98325fe869832ea" alt="Messagemedia3 Pn" width="1919" height="964" data-path="images/Messagemedia3.png" />

Click **Update** to complete the integration setup.

## B. Using the Zuper–Message Media Integration

Once integrated, you can send Text Messages directly from Zuper through Message Media.

1. Navigate to the **Contacts** module from the left navigation menu. Select a contact on the listing page to open its details.

<img src="https://mintcdn.com/zuperinc/sy0JlWjPI2ux23uI/images/Cloudtalk8.png?fit=max&auto=format&n=sy0JlWjPI2ux23uI&q=85&s=3e9af30bbfcf99af776514300b211217" alt="Cloudtalk8 Pn" width="1906" height="873" data-path="images/Cloudtalk8.png" />

3. On the **Contact Details** page, click **More Actions** on the top right corner and select Email/Text Message from the dropdown menu.

Fill in the following fields:

| Field | Description |
| :- | :- |
| **Contact Via (Mandatory)** | Select **Text Message** to send a notification. |
| **Contact Number (Mandatory)** | Choose the contact’s phone number. |
| **Message Body (Mandatory)** | Enter the text message content. |

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk10.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=c1a492f051436055b7758771b2e0a8af" alt="Cloudtalk10 Pn" width="1914" height="874" data-path="images/Cloudtalk10.png" />

Click **Send** to deliver the text message via Message Media.

<Note>
  Note: You can trigger Text Messages via the Contacts module, Bulk Text Message action, or Workflow automation.
</Note>

## C. Uninstalling Message Media from Zuper

If you no longer need the integration, follow the steps below to uninstall the Message Media app.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store**.

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk1.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=2bc9016867f229998cb6d6266d1787fd" alt="Cloudtalk1 Pn" width="1904" height="872" data-path="images/Cloudtalk1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **Message Media**. Click **Deactivate**. You have the option to Uninstall **Message Media**.

<img src="https://mintcdn.com/zuperinc/ZFbeTmwB9cv-vBym/images/Messagemedia1.png?fit=max&auto=format&n=ZFbeTmwB9cv-vBym&q=85&s=9d652cd06ceefaa8146cf4c1a556c3a7" alt="Messagemedia1 Pn" width="1265" height="606" data-path="images/Messagemedia1.png" />

3. The Message Media is uninstalled successfully.

<img src="https://mintcdn.com/zuperinc/ZFbeTmwB9cv-vBym/images/Messagemedia4.png?fit=max&auto=format&n=ZFbeTmwB9cv-vBym&q=85&s=41e4f931ebc98bd7f30e547915421744" alt="Messagemedia4 Pn" width="1868" height="675" data-path="images/Messagemedia4.png" />

A confirmation message will appear once **Message Media** has been successfully uninstalled.
