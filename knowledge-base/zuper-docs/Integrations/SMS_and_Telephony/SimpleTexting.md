# SimpleTexting 

SimpleTexting is a leading cloud-based text messaging platform, trusted by businesses in the North American region for reliable and efficient customer communication.

The Zuper–SimpleTexting integration enables seamless outbound communication by connecting your SimpleTexting account with Zuper. Once integrated, you can automatically send outbound text messages directly from your SimpleTexting number to keep your contacts informed about job updates, pending actions, or service notifications in real-time.

<Note>
  Note: You must have an active SimpleTexting account and subscription to use this integration.
</Note>

## A. Connecting SimpleTexting with Zuper

Follow the steps below to integrate your SimpleTexting account with Zuper.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store** from the dropdown menu.

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext1.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=c78ab493af84ab405440a2711c346c96" alt="Stext1 Pn" width="1904" height="872" data-path="images/Stext1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **SimpleTexting** from the list of available integrations.

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext2.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=041c2f9ec9c938ce87c41ae5807f3add" alt="Stext2 Pn" width="1877" height="852" data-path="images/Stext2.png" />

3. Click **Install SimpleTexting**.

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext3.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=9584d410219d7533bfd24c4a8dd93ff3" alt="Stext3 Pn" width="1884" height="858" data-path="images/Stext3.png" />

4. Update the following fields with details from your SimpleTexting account:

| **Field** | **Description** | **Where to Find** |
| :-: | :-: | :-: |
| **SimpleTexting API Key (Mandatory)** | Enter your SimpleTexting API key to authenticate the integration between Zuper and SimpleTexting. | Log in to SimpleTexting → Dashboard → Profile & Settings → API tab → API Token |
| **Enable SMS Notification (Yes/No)** | Choose **Yes** to enable text message notifications for your contacts. This ensures that Zuper can send outbound text messages via SimpleTexting. | Available under **Contacts → Edit Contact → Notification Preferences** |

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext4.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=b016c9f67d8ef7ddc1f55f685e95268f" alt="Stext4 Pn" width="1920" height="877" data-path="images/Stext4.png" />

Click **Update** to complete the integration setup.

## B. Using the Zuper–SimpleTexting Integration

Once the integration is configured, you can send **Text Messages** directly from Zuper using your SimpleTexting number.

1. Navigate to the **Contacts** module from the left panel. Select a contact on the listing page to open its details.

<img src="https://mintcdn.com/zuperinc/sy0JlWjPI2ux23uI/images/Cloudtalk9.png?fit=max&auto=format&n=sy0JlWjPI2ux23uI&q=85&s=1f6b2a5ba7bd11ff6f6b5e9dc43eab0b" alt="Cloudtalk9 Pn" width="1916" height="842" data-path="images/Cloudtalk9.png" />

2. On the **Contact Details** page, click **More Actions** (top-right corner) and select **Email/Text Message** from the dropdown menu.

Fill in the following fields:

| **Field** | **Description** |
| :-: | :-: |
| **Contact Via (Mandatory)** | Select **SMS** to send a notification. |
| **Contact Number (Mandatory)** | Choose the contact’s phone number. |
| **Message Body (Mandatory)** | Enter the message content. |

Click **Send** to deliver the text message via SimpleTexting.

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk10.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=c1a492f051436055b7758771b2e0a8af" alt="Cloudtalk10 Pn" width="1914" height="874" data-path="images/Cloudtalk10.png" />

<Note>
  Note: You can trigger messages via the Contacts module, Bulk Text Message action, or Workflow automation.
</Note>

## C. Uninstalling SimpleTexting from Zuper

If you no longer need the integration, follow the steps below to uninstall the SimpleTexting app.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store**.

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext1.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=c78ab493af84ab405440a2711c346c96" alt="Stext1 Pn" width="1904" height="872" data-path="images/Stext1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **SimpleTexting.** You have the option to Uninstall **SimpleTexting**.

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext2.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=041c2f9ec9c938ce87c41ae5807f3add" alt="Stext2 Pn" width="1877" height="852" data-path="images/Stext2.png" />

3. The SimpleTexting is uninstalled successfully.

<img src="https://mintcdn.com/zuperinc/p5yY7PUxHUhdXE-D/images/Stext5.png?fit=max&auto=format&n=p5yY7PUxHUhdXE-D&q=85&s=73aee78a93f46054122d3ca03fb2a8c1" alt="Stext5 Pn" width="1898" height="875" data-path="images/Stext5.png" />

With this one-way integration, data flows from **Zuper to SimpleTexting**, ensuring that customers receive instant SMS notifications for the latest job updates, appointments, and service alerts—enhancing both communication and customer satisfaction.
