# Invisible Link 

Invisible Link is a widely used SMS application based in the European region, trusted for reliable message delivery and easy integration with business workflows.

The Zuper–Invisible Link SMS integration enables seamless communication by connecting your Invisible Link account with Zuper. Once integrated, you can automatically send outbound Email/Text Messages directly through your Invisible Link number, keeping your contacts informed about pending items, job updates, or service notifications in real time.

<Note>
  Note:

  * This integration is available to all users with an active Invisible Link plan, regardless of your location.
  * Ensure that **Text Message/Text Notifications** are enabled for your contacts.\
    \
    **Navigation:** Contacts → Contacts Listing page → Edit (via three-dot icon) → Edit Contact page → Notification Preferences
</Note>

## A. Connecting Invisible Link SMS with Zuper

Follow the steps below to integrate your Invisible Link account with Zuper.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store** from the dropdown menu.

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink1.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=114cfb76896430b2520a43ed62dfc6ea" alt="Ilink1 Pn" width="1903" height="872" data-path="images/Ilink1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **Invisible Link** from the list of available integrations.

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink2.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=06a0a826d2ccd272af0aa15e6afec628" alt="Ilink2 Pn" width="1920" height="886" data-path="images/Ilink2.png" />

3. Click **Install Invisible Link**.

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink3.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=daef822bb8348570d945bb8139246c02" alt="Ilink3 Pn" width="1909" height="835" data-path="images/Ilink3.png" />

<Tip>
  Tip: Keep both Zuper and Invisible Link tabs open during setup to switch between accounts easily.
</Tip>

4. Update the following fields with details from your Invisible Link account:

| Field | Description | Where to Find |
| :- | :- | :- |
| **Invisible API Key (Mandatory)** | Enter the Invisible Link API key. | Go to **Settings → Developer Section → API Key → Generate API Key** on Invisible Link. |
| **Invisible Link User Name (Mandatory)** | Enter the login name used for Invisible Link. | Use your login username from the Invisible Link login page. |
| **Invisible Link Sender Name/Number (Mandatory)** | Enter the sender name/number from which messages will be sent. | Go to **Send → Single SMS → Alphanumeric Sender** on Invisible Link. |

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink4.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=6ed3803932d56e23f367c4a6500859c7" alt="Ilink4 Pn" width="1920" height="886" data-path="images/Ilink4.png" />

Click **Update** to complete the integration.

## B. Using the Zuper–Invisible Link SMS Integration

Once integrated, you can send **Email/Text Messages** directly from Zuper.

1. Navigate to the **Contacts** module from the left panel.

   <img src="https://mintcdn.com/zuperinc/sy0JlWjPI2ux23uI/images/Cloudtalk8.png?fit=max&auto=format&n=sy0JlWjPI2ux23uI&q=85&s=3e9af30bbfcf99af776514300b211217" alt="Cloudtalk8 Pn" width="1906" height="873" data-path="images/Cloudtalk8.png" />
2. Select a **contact** from the listing page to open its details.

   On the **Contact Details** page, click ****More Actions (at the top right corner) and selectEmail/Text Message****  from the dropdown menu.

   <img src="https://mintcdn.com/zuperinc/sy0JlWjPI2ux23uI/images/Cloudtalk9.png?fit=max&auto=format&n=sy0JlWjPI2ux23uI&q=85&s=1f6b2a5ba7bd11ff6f6b5e9dc43eab0b" alt="Cloudtalk9 Pn" width="1916" height="842" data-path="images/Cloudtalk9.png" />
3. Fill in the following fields:

| Field | Description |
| :- | :- |
| **Contact Via (Mandatory)** | Select **Text Message** to send a notification. |
| **Contact Number (Mandatory)** | Choose the contact’s phone number. |
| **Message Body (Mandatory)** | Enter the message content. |

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk10.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=c1a492f051436055b7758771b2e0a8af" alt="Cloudtalk10 Pn" width="1914" height="874" data-path="images/Cloudtalk10.png" />

Click **Send** to deliver the text message via Invisible Link.

<Note>
  Note: You can trigger messages via the Contacts module, Bulk Text Message action, or Workflow automation.
</Note>

## C. Uninstalling Invisible Link from Zuper

If you no longer need the integration, follow the steps below to uninstall the Invisible Link app.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store**.

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink1.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=114cfb76896430b2520a43ed62dfc6ea" alt="Ilink1 Pn" width="1903" height="872" data-path="images/Ilink1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **Invisible Link**. You have the option to Uninstall **Invisible Link**.

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink2.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=06a0a826d2ccd272af0aa15e6afec628" alt="Ilink2 Pn" width="1920" height="886" data-path="images/Ilink2.png" />

3. The Invisible Link is uninstalled successfully.

<img src="https://mintcdn.com/zuperinc/DYyR6NKRncbC5ube/images/Ilink5.png?fit=max&auto=format&n=DYyR6NKRncbC5ube&q=85&s=76ff2d354879da022cbed710d0f53b5a" alt="Ilink5 Pn" width="1920" height="890" data-path="images/Ilink5.png" />

A confirmation message will appear once **Invisible Link** has been successfully uninstalled.
