# Sales Message 

**Sales Message** is a widely used SMS application based in the USA region, trusted by businesses for reliable message delivery, two-way communication, and easy integration with various business tools.

The **Zuper–Sales Message Link SMS integration** enables seamless communication by connecting your **Sales Message** account with **Zuper**. Once integrated, you can automatically send outbound **Email/Text Messages** directly through your **Sales Message** number, ensuring that your contacts stay informed about important updates such as job progress, appointment reminders, and service notifications in real time.

<Note>
  Note:

  * This integration is available to all users with an active Sales Message Link plan, regardless of their location.
  * You must create a Sales Message developer account and subscribe to any Sales Message SMS pricing plan to enable this integration.
  * Ensure that Text Message/Text Notifications are enabled for your contacts.

  Navigation: Contacts → Contacts Listing page → Edit (via three-dot icon) → Edit Contact page → Notification Preferences
</Note>

### A. Connect Sales Message with Zuper

1. Log in to your Zuper account and click your **profile picture in** the top right corner. From the dropdown menu, select **App Store**.

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk1.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=2bc9016867f229998cb6d6266d1787fd" alt="Cloudtalk1 Pn" width="1904" height="872" data-path="images/Cloudtalk1.png" />

2. Under **Browse by Category**, choose **Telephony, Video, & SMS** and select **Sales Message**.

<img src="https://mintcdn.com/zuperinc/r92h1Fvv34DZ61eG/images/Smessage1.png?fit=max&auto=format&n=r92h1Fvv34DZ61eG&q=85&s=4dadb4a540429c2d5d8cb86c083471fd" alt="Smessage1 Pn" width="1921" height="881" data-path="images/Smessage1.png" />

3. Click **Install Sales Message**.

<img src="https://mintcdn.com/zuperinc/r92h1Fvv34DZ61eG/images/Smessage2.png?fit=max&auto=format&n=r92h1Fvv34DZ61eG&q=85&s=e8790f0f6a445d7e2e468c28a6126d1b" alt="Smessage2 Pn" width="1921" height="881" data-path="images/Smessage2.png" />

<Tip>
  Tip: Keep both the Zuper and Sales Message tabs open to switch between them during setup easily.
</Tip>

5. Configure the following fields in the Sales Message integration setup:

| **Field Name** | **Description** |
| :-: | :-: |
| **Zuper API Key** *(Mandatory)* | Enter your Zuper [API](https://docs.zuper.co/Settings/Developer_Hub/API_Keys#api-keys) Key. |
| **Personal Access Token** *(Mandatory)* | Enter your Sales Message Client ID.<br />To get this, go to **Sales Message → Settings → Developer Settings → Personal Access Tokens → Create Token.** |
| **Sales Message Team Name** *(Mandatory)* | Enter your Sales Message Team Name.<br />To find it, go to **Sales Message → Settings → Organization → Inboxes → Name.** |

### B. Send Text Messages via Sales Message Integration

Once connected, Zuper uses the Sales Message integration to send Text Notifications automatically to your contacts.

1. Navigate to the **Contacts** module from the left navigation menu. Select a contact on the listing page to open its details.

<img src="https://mintcdn.com/zuperinc/sy0JlWjPI2ux23uI/images/Cloudtalk9.png?fit=max&auto=format&n=sy0JlWjPI2ux23uI&q=85&s=1f6b2a5ba7bd11ff6f6b5e9dc43eab0b" alt="Cloudtalk9 Pn" width="1916" height="842" data-path="images/Cloudtalk9.png" />

2. On the **Contact Details** page, click **More Actions** (top right corner)**→ Email/Text Message**.

<img src="https://mintcdn.com/zuperinc/sy0JlWjPI2ux23uI/images/Cloudtalk9.png?fit=max&auto=format&n=sy0JlWjPI2ux23uI&q=85&s=1f6b2a5ba7bd11ff6f6b5e9dc43eab0b" alt="Cloudtalk9 Pn" width="1916" height="842" data-path="images/Cloudtalk9.png" />

3. In the **Email/Text Message** window, configure the following fields:

* **Contact Via (Mandatory)** – Select **Text Message**.
* **Contact Number (Mandatory)** – Choose the number to send the message to.
* **Message Body (Mandatory)** – Enter your message content.

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk10.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=c1a492f051436055b7758771b2e0a8af" alt="Cloudtalk10 Pn" width="1914" height="874" data-path="images/Cloudtalk10.png" />

5. Click **Send** to send a Text Message via your connected Sales Message account.

### C. Uninstall Sales Message from Zuper

If you no longer need the integration, follow the steps below to uninstall the Sales Message app.

1. Log in to your **Zuper web app**. Click your **Profile Picture** in the top-right corner. Select **App Store**.

<img src="https://mintcdn.com/zuperinc/YpQ83C8aE_U-mgzA/images/Cloudtalk1.png?fit=max&auto=format&n=YpQ83C8aE_U-mgzA&q=85&s=2bc9016867f229998cb6d6266d1787fd" alt="Cloudtalk1 Pn" width="1904" height="872" data-path="images/Cloudtalk1.png" />

2. Under **Browse by Category**, select **Telephony, Video & SMS**. Choose **Sales Message.** You have the option to Uninstall **Sales Message**.

<img src="https://mintcdn.com/zuperinc/r92h1Fvv34DZ61eG/images/Smessage1.png?fit=max&auto=format&n=r92h1Fvv34DZ61eG&q=85&s=4dadb4a540429c2d5d8cb86c083471fd" alt="Smessage1 Pn" width="1921" height="881" data-path="images/Smessage1.png" />

3. The Sales Message is uninstalled successfully.
