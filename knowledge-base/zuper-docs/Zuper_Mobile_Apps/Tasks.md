# Tasks

Creating a Task on the Zuper mobile app is easy. Tasks can be used to schedule internal activities or follow-ups that do not require creating a formal service job. You can create tasks as standalone items or associate them with a job or project.

Tasks can be created from the following places in the Zuper mobile:

* From the **Dashboard**, tap **My Tasks** in Quick Links → tap the **+** icon (bottom right).

## Creating a task

From the new task screen, you will be prompted to enter:

* Enter your task with a clear, descriptive **title**.
* Give your Task a **description**.
* Set the task **due date.**
* Choose a **task type** from the list. By default, the “*Task*” as a type will be filled in. You can choose to modify if required.
* Select a **priority** level.
* **Assign** the task to yourself or to a team member.
  <Note>
    **Note**: If you’re logged in as a Field Executive, the task is automatically assigned to you.
  </Note>
* Tap the **+** icon for additional options:
  * **Set Reminder**: Schedule reminders to help the assignee act on time. This option appears only after a **Due Date** is set in the task. The assignee will receive the push notification on their device.
  * **Associated Module:** Link to a Job or Project (auto-linked if created from a Job/Project). Linked tasks also appear in the Job/Project's **Tasks** tab.
  * **Inspection form**: Attach a form that must be completed before closing the task.
  * **Attachments**: Upload relevant files or documents to support the task with additional context or details.

After entering all the required details, click “**Create**”. The assigned user receives a push notification for the assignment.

When you are viewing a Job or Project in Zuper, you can easily add a Task by **tapping** on the **+ icon** located in the \*\*Tasks \*\*tab.

#### Available action in the Tasks tab

Tap the Context menu(⋮), you can:

* **Change execution type** – Define how tasks should be completed (Parallel or Serial execution).
* **Reorder tasks** – Change the order of tasks.
* **Remove all tasks** – Delete everything if needed.

## Managing your tasks

Once tasks are assigned to you, you can manage them directly from the **Tasks** screen in the Zuper mobile app. This section explains the actions you can perform on a task and how each action helps you stay on top of your work.

### View and organize tasks

From the **Tasks** screen, tasks are grouped to help you quickly prioritize your work. You can tab to switch Task views between:

* **Today** – Displays tasks scheduled for the current day. Tasks are sorted by **created date**.
* **Overdue** – Displays tasks that have passed their due date. Tasks are sorted by **due date**.
* **All Tasks** – Displays all tasks assigned to you. Tasks are sorted by **created date**.

<img src="https://mintcdn.com/zuperinc/FUsaqCmQ192_mXRO/Zuper_Mobile_Apps/Images/tasking-07.png?fit=max&auto=format&n=FUsaqCmQ192_mXRO&q=85&s=0448c980d36886594c8c04dbc077eb42" style={{ height:"690px",width:"350px" }} className="rounded-lg" width="1570" height="2932" data-path="Zuper_Mobile_Apps/Images/tasking-07.png" />

To customize your view, you can use the **Filter** option in the upper-right-hand corner. You can filter tasks based on priority, task type, assignee, status, and due date.

(The due date filter is available in Overdue and All Tasks views, but not in Today, since it displays only current-day tasks).

<img src="https://mintcdn.com/zuperinc/FUsaqCmQ192_mXRO/Zuper_Mobile_Apps/Images/tasking-08.png?fit=max&auto=format&n=FUsaqCmQ192_mXRO&q=85&s=abfb81e60182f190751d382581ff0b84" style={{ height:"690px",width:"350px" }} className="rounded-lg" width="1570" height="2932" data-path="Zuper_Mobile_Apps/Images/tasking-08.png" />

<Note>
  **Note**: User who do not have Admin-level permissions for their account will only be able to see their own tasks. If you have Admin-level permission, you can select the “*Include team tasks*” checkbox in the **Filter** menu to view all team member tasks.
</Note>

### Open a task

Tap on a task to view the **Task details**. From here, you can:

* Review task information
* View the associated Job or Project
* Track and update the task status
* Update the due date, task type, priority, or reminder 
* Complete the inspection form (if an Inspection Form is associated to the task)

<img src="https://mintcdn.com/zuperinc/FUsaqCmQ192_mXRO/Zuper_Mobile_Apps/Images/tasking-13.png?fit=max&auto=format&n=FUsaqCmQ192_mXRO&q=85&s=eeeb9391ea5084b3a7dedcc4b861fecd" style={{ height:"690px",width:"350px" }} className="rounded-lg" width="1570" height="2932" data-path="Zuper_Mobile_Apps/Images/tasking-13.png" />

On the **Task** details page, you can also manage your task with the following options available in the context menu (⋮):

* Edit
* Clone
* Task Status History
* Delete

### Updating a task’s status

Task status indicators (such as **In Progress, On-Hold,** or **Completed**) help you quickly understand the current state of each task. This ensures better visibility and smoother coordination when tasks are linked to jobs or projects.

To update a task’s status:

1. Tap on the task for which you want to update the status.
2. On the details page, select the relevant status and provide the remarks if required.

<img src="https://mintcdn.com/zuperinc/FUsaqCmQ192_mXRO/Zuper_Mobile_Apps/Images/tasking-04.png?fit=max&auto=format&n=FUsaqCmQ192_mXRO&q=85&s=66a25f5f869693825ddb7727820e4005" style={{ height:"690px",width:"350px" }} className="rounded-lg" width="1570" height="2932" data-path="Zuper_Mobile_Apps/Images/tasking-04.png" />

**How the radio button works for completion:**

* If an **inspection form** is attached to the task: Tapping the radio button on the task listing will open the inspection form for you to complete it. Once the form is submitted, you can then mark the task as completed.
* If no **inspection form** is attached: Tapping the radio circle will directly mark the task as Completed.
