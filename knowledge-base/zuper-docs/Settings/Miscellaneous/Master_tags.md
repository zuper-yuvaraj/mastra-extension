# Master Tags

Master tags in Zuper are a powerful organizational tool designed to help you categorize and manage various modules, such as Jobs, Customers, Quotations, Invoices, and Projects.

<Frame>
  **Navigation**: *Settings -> Miscellaneous -> Master Tags*
</Frame>

1. From the settings, select “**Miscellaneous**." Under the "**Master Tags**" section, choose “**+ New Tag."**

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/MT1.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=9e2669ab99d4ea53a9cd9810e994c81c" alt="MT1 Pn" width="1908" height="872" data-path="images/MT1.png" />

2. Enter the following details.

* **Tag Name**: Enter a unique name for the tag. This field is mandatory.
* From the **Module** dropdown, you can select the module you want to map this tag to. This field is required.
  * Jobs
  * Customers
  * Quotations
  * Invoice
  * Projects
  * Gallery
    These fields are also mandatory. This determines where the tag will be mapped to the modules.
* **Description** - Enter the master tag description.

<Frame>
  <img src="https://mintcdn.com/zuperinc/QIdOlpninyKIFRK5/images/mtgall1.png?fit=max&auto=format&n=QIdOlpninyKIFRK5&q=85&s=05e8a1b1afb56d0393f6b75ea3b7572c" alt="Mtgall1" width="1905" height="868" data-path="images/mtgall1.png" />
</Frame>

3. The tag is created successfully.

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/MT3.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=bc359eef8972b300f203e776b7960694" alt="MT3 Pn" width="1909" height="867" data-path="images/MT3.png" />

4. Choose the "**Module**" filter to filter the list of module line items. Tags can be edited or deleted using the action icons in the table.

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/MT4.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=d5a3c2e05494b4f04d9ca4e1716ed386" alt="MT4 Pn" width="1910" height="875" data-path="images/MT4.png" />

The process of creating a new tag is straightforward—simply enter a unique tag name, select the appropriate module, and save.
