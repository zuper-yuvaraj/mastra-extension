# Custom Dashboards

Custom Dashboards in Zuper allow you to create personalized views to track key metrics and data relevant to your business operations. This article guides you through the process of creating, viewing, and managing custom dashboards.

<Frame>
  **Navigation**: *Settings -> Miscellaneous -> Custom Dashboard*
</Frame>

1. From the settings, select “**Miscellaneous**." From the "**Custom Dashboards**" section, choose “**+ New Dashboard**."

<img src="https://mintcdn.com/zuperinc/foY4ItPnEcbwC0iC/images/CD1.png?fit=max&auto=format&n=foY4ItPnEcbwC0iC&q=85&s=8c3c4f285fcc49827cbbb7470214b544" alt="CD1 Pn" width="1918" height="868" data-path="images/CD1.png" />

2. A "**Create New Dashboard**" dialog box appears. Fill in the following details.

* **Name**: Enter a unique name for your dashboard.
* **Channel**: Select the channel where the dashboard will be available.
* **URL**: Provide the URL of the dashboard content. This could be a link to a third-party analytics tool or a custom dashboard URL (A sample URL: [*https://pre-sales.travis-gitlab-content-marketing/ll*](https://pre-sales.travis-gitlab-content-marketing/ll)).
* **Applicability**: Choose who can access the dashboard (e.g., Everyone or specific roles/users).
* **Use this as a default dashboard?**: Check this box if you want this dashboard to be the default view for the selected users.

<img src="https://mintcdn.com/zuperinc/foY4ItPnEcbwC0iC/images/CD2.png?fit=max&auto=format&n=foY4ItPnEcbwC0iC&q=85&s=03f04b6da65e15fe40a7f4ab6f10bdfe" alt="CD2 Pn" width="1912" height="870" data-path="images/CD2.png" />

Click "**Create**" to create the custom dashboards.

3. The "**Custom Custom Dashboard**" is successfully created.

<img src="https://mintcdn.com/zuperinc/foY4ItPnEcbwC0iC/images/CD3.png?fit=max&auto=format&n=foY4ItPnEcbwC0iC&q=85&s=4c51355100e8c66ea6728d26aff14782" alt="CD3 Pn" width="1919" height="875" data-path="images/CD3.png" />

## Best Practices

* **Naming**: Use descriptive names for dashboards to easily identify their purpose (e.g., "Sales Dashboard", "Tax Overview").
* **Access Control**: Set the **Applicability** field thoughtfully to ensure only the intended users can access sensitive data.
* **Default Dashboards**: Use the default dashboard option for frequently used dashboards to save time.
