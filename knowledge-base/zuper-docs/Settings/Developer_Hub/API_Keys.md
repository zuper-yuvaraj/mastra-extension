# API Keys

Zuper API Keys are essential for securely authenticating and authorizing access to the Zuper API. These keys enable seamless integration with Zuper's services, allowing developers to build powerful applications that leverage real-time data and functionality.

<Frame>
  **Navigation**: *Settings -> Developer Hub -> API Keys*
</Frame>

1. From the settings, select “**Developer Hub**," choose “**API Keys**," and click "**+New API Key**."

<img src="https://mintcdn.com/zuperinc/1rmk76XRWAyXLx-q/images/API1.png?fit=max&auto=format&n=1rmk76XRWAyXLx-q&q=85&s=054b332372b84d8cc7e672e68b63c479" alt="API1 Pn" width="1920" height="871" data-path="images/API1.png" />

2. A “**New API Key**” dialog box appears. Enter the “**API Key Name**.” Click the “**Create**” button to generate the API key.

<img src="https://mintcdn.com/zuperinc/1rmk76XRWAyXLx-q/images/API2.png?fit=max&auto=format&n=1rmk76XRWAyXLx-q&q=85&s=0e48860d5b31aba96f1ee30c9475b694" alt="API2 Pn" width="1907" height="884" data-path="images/API2.png" />

3. The API key is successfully created. Click the  <Icon icon="copy" />  button to copy the API key.

<img src="https://mintcdn.com/zuperinc/1rmk76XRWAyXLx-q/images/API3.png?fit=max&auto=format&n=1rmk76XRWAyXLx-q&q=85&s=b1d8540fbdc3c7418a78f8e3344267a7" alt="API3 Pn" width="1895" height="866" data-path="images/API3.png" />

4. Under “**Actions**,” you can view or delete the API key.

<img src="https://mintcdn.com/zuperinc/1rmk76XRWAyXLx-q/images/API4.png?fit=max&auto=format&n=1rmk76XRWAyXLx-q&q=85&s=f3532ae204ffd174d5d880fb8f469790" alt="API4 Pn" width="1920" height="870" data-path="images/API4.png" />

Users can ensure their applications interact with Zuper's ecosystem efficiently and securely by generating and managing API keys.

### Troubleshooting

<Note>
  **Note:** QuickBooks Online (QBO) sync activities might not trigger records created or updated through an API key user, depending on your system configuration. To avoid this, create a dedicated user account for your QBO integration. Then generate the API key from that account. This keeps your integration activity separate, easier to track, and more consistent over time.
</Note>
