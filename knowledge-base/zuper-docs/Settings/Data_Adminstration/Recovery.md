# Recovery

Accidentally deleted a line item from a module in Zuper, such as an invoice, job, or estimate? Don’t worry, Zuper provides a straightforward way to recover deleted line items, ensuring you can restore essential details like products, services, or tasks without starting over.

<Frame>
  **Navigation**: *Settings -> Data Administration -> Recovery*
</Frame>

1. Select the “**Settings**” module from the left panel. Under the “**Data Administration**,” choose the  “**Recovery**.”

<img src="https://mintcdn.com/zuperinc/xykriCG8yCRPW26t/images/Reco1.png?fit=max&auto=format&n=xykriCG8yCRPW26t&q=85&s=6a23247792f059e5bc239aeaa219e290" alt="Reco1 Pn" width="1907" height="869" data-path="images/Reco1.png" />

2. Under the modules filter, select the module. Click the recover icon to restore the line item.

<img src="https://mintcdn.com/zuperinc/xykriCG8yCRPW26t/images/Reco2.png?fit=max&auto=format&n=xykriCG8yCRPW26t&q=85&s=0f512bd47bc9389e5490a51ae026eb97" alt="Reco2 Pn" width="1912" height="866" data-path="images/Reco2.png" />

3. Click the "**Recove**r" button to recover the line item.

<img src="https://mintcdn.com/zuperinc/xykriCG8yCRPW26t/images/Reco3.png?fit=max&auto=format&n=xykriCG8yCRPW26t&q=85&s=453efeb7c63dae219394c05ae76cdc5b" alt="Reco3 Pn" width="1916" height="863" data-path="images/Reco3.png" />

4. The job is recovered successfully.

<img src="https://mintcdn.com/zuperinc/xykriCG8yCRPW26t/images/Reco4.png?fit=max&auto=format&n=xykriCG8yCRPW26t&q=85&s=fd474e45cde8a79628ba8c8967f72f26" alt="Reco4 Pn" width="1915" height="872" data-path="images/Reco4.png" />

<Note>
  Note: You can recover deleted line items within 90 days. After 90 days, recovery will no longer be possible.
</Note>

| Module | Supports Recovery |
| - | - |
| **Jobs** | ✅ Yes |
| **Projects** | ✅ Yes |
| **Contacts** | ✅ Yes |
| **Organizations** | ✅ Yes |
| **Properties** | ✅ Yes |
| **Parts & Services** | ✅ Yes |
| **Quotes** | ✅ Yes |
| **Invoices** | ✅ Yes |
| **Contracts** | ✅ Yes |
| **Assets** | ✅ Yes |
| **Users** | ✅ Yes |
| **Purchase Orders** | ✅ Yes |
| **Material Requests** | ✅ Yes |
| **Timesheets** | ❌ No |
| **Teams** | ❌ No |

<Warning>
  Timesheets and the Teams module's line items are permanently deleted at the module level and are not logged or listed in the Recovery settings.
</Warning>

This feature helps maintain record accuracy and minimizes disruptions to workflow, keeping operations running smoothly.
