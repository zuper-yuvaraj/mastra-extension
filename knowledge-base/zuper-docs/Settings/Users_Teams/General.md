# User & Team Settings

<Frame>
  **Navigation**: *Settings -> Users - > Users General Settings*
</Frame>

## **Users & Teams general settings**

* Select the "**Settings**" module from the left panel. Choose the "**Users and Teams**." Select the "**Users General Settings**."

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use21.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=9526d85b6cf88653a552d6facf1d854f" alt="Use21 Pn" width="1919" height="869" data-path="images/use21.png" />

* User Prefix - Enter the default prefix that needs to be added to the user ID.
* Can Field Executive upload files? - Toggle the switch to **Yes** to permit field executives to upload files or **No** to disable this feature.
* Track user location using? - Select **Timelog** from the dropdown menu to enable location tracking via **Timelog**, or choose Timesheet from the dropdown menu to enable location tracking via **Timesheet**.

### **Shift management**

* Can Field Executive edit Shift? - Toggle the switch to **Yes** to permit field executives to edit shift or **No** to disable this feature.

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use22.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=571d3679d5fccea4935e77db31e23ff8" alt="Use22 Pn" width="1913" height="872" data-path="images/use22.png" />

### **Wage information**

* Enable hourly labor charges -  Toggle the switch to **Yes** to activate hourly labor charges for your team.
* Default Hourly Labor Charges (**Mandatory**) - Enter the default hourly rate in USD. This rate will apply unless overridden by the Admin or Team Leader at the module level.
* Minimum Roundup Multiple Number (**Mandatory**)  - Set the minimum time increment for rounding labor charges.
* Worker Comp Code - Enter the Worker Compensation Code for your team. This field tracks and reports worker compensation details.
* Burden Rate - Input the burden rate and choose the percentage, multiplier or addition from the drop down menu. This rate accounts for additional costs (e.g., benefits, taxes) applied to labor charges.

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use23.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=ba056d72b7af74e46f7207ea95a2e499" alt="Use23 Pn" width="1910" height="857" data-path="images/use23.png" />

Click the "**Save**" button to save the user's general settings.

## **Team management**

The Team management allows you to create, view, and manage teams efficiently.

**Navigation**: *Settings -> Modules -> Users - > Team Custom Fields*

1. Select the "**Settings**" module from the left panel. Under the "**Modules**," choose the "**Users and Teams**." Select the "**Team Management**."

<img src="https://mintcdn.com/zuperinc/A5eElFuTAkZCdwLe/images/Team1.png?fit=max&auto=format&n=A5eElFuTAkZCdwLe&q=85&s=b682a88c519c140726ba5e73331b2683" alt="Team1 Pn" width="1912" height="867" data-path="images/Team1.png" />

2. Under "**Team Management**," Click the "**+ Create New Team"** button at the top right corner of the page.

<img src="https://mintcdn.com/zuperinc/A5eElFuTAkZCdwLe/images/Team3.png?fit=max&auto=format&n=A5eElFuTAkZCdwLe&q=85&s=9bf155f781a0f617ca078aa1730072d5" alt="Team3 Pn" width="1911" height="863" data-path="images/Team3.png" />

3. Fill in the details.

* **Team Name (Mandatory)**: Enter a unique name for your team. This field is required.
* **Team Color**: Select a color for your team from the available options. This helps visually distinguish the team in the list.
* **Timezone**: Choose the appropriate timezone for the team.
* **Team Description**:  Briefly describe the team’s purpose or role.
* <Badge color="green">New</Badge> **Non-Dispatchable**: Select this checkbox to mark a team as non-dispatchable. When selected, the team is hidden from the Dispatch Board team picker, preventing dispatchers from assigning jobs to it.<br />This is especially useful in blocking back-office (or) operations teams such as Finance, HR, Warehouse, etc., from being dispatched to. Helps the Dispatch Board focus only on field teams. If the checkbox is left unselected (*which is the default*), the teams will remain visible on the Dispatch Board. <img src="https://mintcdn.com/zuperinc/tdJdzlHUQocaxakj/images/dispatchable.png?fit=max&auto=format&n=tdJdzlHUQocaxakj&q=85&s=1201e0fa6276a4e1a960f66077501164" alt="Dispatchable" width="1920" height="869" data-path="images/dispatchable.png" />

Click "**Create**"  to create the new team.

## **Custom roles**

<Frame>
  **Navigation**: *Settings -> Modules -> Users - > Custom Roles*
</Frame>

1. Select the "**Settings**" module from the left panel. Under the "**Modules**," choose the "**Users and Teams**." Select the "**Custom Roles**."

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use17.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=3e3e8db7fb6f0670a2ced7eb74a39765" alt="Use17 Pn" width="1907" height="871" data-path="images/use17.png" />

2. Under the Custom Roles section, click the **+ New Role** button.

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use18.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=14c60b7a4ea45a0697ebac39b2998303" alt="Use18 Pn" width="1918" height="870" data-path="images/use18.png" />

3. Under the **Permissions** tab, select a module from the **List of Modules** (e.g., Jobs). Toggle the permissions you want to enable for this role. To grant all permissions for a module, toggle the **Enable All Permissions** switch.

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use19.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=c1ad32a27d72fa27f83dc1d4901ba660" alt="Use19 Pn" width="1901" height="867" data-path="images/use19.png" />

4. Under the **Users** tab, select users to assign to this role from the Available Users list. Users can only have one role at a time, so assigning a new role will unassign their existing role. Selected users will appear in the **Users Assigned** section.

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use20.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=7b8df4e3c987ee92b56d76fc22f3aff9" alt="Use20 Pn" width="1918" height="876" data-path="images/use20.png" />

Click "**Save Role**" to create the custom role.

<Note>
  **Note:** Custom role permissions control actions within a module, such as creating or updating a quote. A few permissions apply to specific fields, for example, **Update Line Item Price** in Quotes. Fields without their own permission are controlled by the module's general update permission. For example, the accepted date on a quote is controlled by **Update Quote**.

  Hiding specific items within a module, such as individual services, based on user roles is not currently supported. Action buttons and icons for restricted actions remain visible to all users. For users who lack the required permission, they appear grayed out (disabled) rather than hidden.
</Note>

## **User custom fields**

<Frame>
  **Navigation**: *Settings -> Modules -> Users - > Users Custom Fields*
</Frame>

1. Select the "**Settings**" module from the left panel. Under the "**Modules**," choose the "**Users and Teams**." Select the "**User Custom Fields**."

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use10.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=760eaee81b0f98cbb2cf4fdde56a6f32" alt="Use10 Pn" width="1916" height="874" data-path="images/use10.png" />

Text

* Single-Line Input: This allows you to create a field to enter a single line of free text.
* Multi-Line Input: This allows you to create a field to enter multiple lines of free text.

Date

* Date Input: This allows you to create a field to select a specific date from a calendar.
* Time Input: This allows you to create a field where you can select a specific time.
* Date Time Input: This allows you to create a field where both date and time can be selected.

Selection

* Single-Selection: This allows you to create a radio input Field where one of the provided options can be selected.
* Multi-Selection: This allows you to create check boxes where the provided options can be checked.
* Drop-Down: This allows you to create a drop-down field with the required list of options.

Media

* Upload: This allows you to create a file input field to upload files.

Misc

* Look up : This allows you to create a file input field to look up the products from the parts and services module.

<Note>
  Note: You can also control the behavior and visibility of each field using the following options:

  * Mark as Required Field -  Makes the field mandatory to fill out before submitting the form.
  * Mark as Read Only—This option makes the field non-editable; users can view the value but cannot modify it.
  * Mark as hidden field- This hides the field from all users; it will not appear in the form interface.
  * Hide to FE/Technician- This option makes the field invisible to technicians or front-end users during form access.
</Note>
