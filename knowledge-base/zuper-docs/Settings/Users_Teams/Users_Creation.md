# Managing your users

This step-by-step guide helps you effortlessly create a new user in Zuper. Whether you're adding team members or assigning roles, this process ensures smooth onboarding. Follow the instructions below to set up a user account quickly and efficiently.

<Frame>
  **Navigation**: *Settings -> Users and Teams -> User Management -> + New User*
</Frame>

Steps to create a user directly from the "**Users**" Tab

* Select the "**Settings**" icon from the left navigation menu. Under "**User Management**," click the "**+ Create New User**" button at the top right corner of the page.

Fill in the details in the user form as follows.

* Upload Image: Upload the user image in a size of 2 MB.

## Basic information

* User ID (**Mandatory**): A unique code that can include both letters and numbers to identify the User.
* First Name (**Mandatory**): The user's First Name.
* Last Name (**Mandatory**): The user's Last Name.
* Designation (**Mandatory**): The user's designation as per the policy.

## Product location

* Preferred Product Location: This enhancement enables a user to be assigned a default product location, ensuring that it automatically populates as the default location from which parts are consumed. A primary method is to define fixed, high-priority picking locations for fast-moving parts or products to the site.

* Home Number: The user's home number.

## Login information

* Email (**Mandatory**): The user's email address.
* Password (**Mandatory**): The password that would be used to access the Zuper account.
* External Login ID: The external login ID for the user to log in.
* Allow user to set the password: Choose "**Yes**" to allow the user to set the password as "**No**"

**Admins now have more flexibility when creating users:**

**Option 1**: **Allow User to Set Password = Yes**

Password fields will be hidden on the user creation/edit page.

The invite email will include a temporary set password link valid for 24 hours.

Users will be directed to a password setup page upon clicking the link.

If the link expires, users can follow the "Forgot Password" flow, as explained in the email.

**Option 2**:  **Allow User to Set Password = No**

The current process continues, and the admin sets the password during user creation.

Users will need to obtain their login password directly from the admin.

## User skills

* Click "**+ Add Skill**" to add new skills.

<img src="https://mintcdn.com/zuperinc/MZ52TIC7PBru9w8k/images/use2.png?fit=max&auto=format&n=MZ52TIC7PBru9w8k&q=85&s=a35f8bf99ec15acb5127bfb37ace6521" alt="Use2 Pn" width="1910" height="876" data-path="images/use2.png" />

* Select Skill: Choose the skillset from the drop-down list.
* Skillset Level: Enter the user's skill set.
* Valid From: The start date of the skill validity.
* Valid To: The end date of the skill validity.

<img src="https://mintcdn.com/zuperinc/BZDESyCbdH9DmDch/images/use3.png?fit=max&auto=format&n=BZDESyCbdH9DmDch&q=85&s=48cd9356e0df649d11a866ba61128dc5" alt="Use3 Pn" width="1919" height="876" data-path="images/use3.png" />

Click the "**Assign Skill**" to assign the skills to the user.

<Note>
  **How technician skills are matched to jobs:** Zuper auto-populates required technician skills based on the skillsets mapped to a job's category. To have skills applied automatically, map the relevant skillsets to your job categories under Settings. Skill matching and slot selection are performed per job through Assisted Scheduling; route optimization is a separate operation.
</Note>

## Work hours

* Work Hours: The user's work days of the week.
* From Time: The start of the working day.
* To Time: The end of the working day.
* Work Mins: The total work minutes of the week.
* Tracking Location? Choose "**Yes**" to track the user's location and "**No**" to deny tracking the location. This works together with the organization-level [location tracking setting](/Settings/Users_Teams/General#users-teams-general-settings) and [device-level location permissions](https://docs.zuper.co/Settings/Users_Teams/General#faqs)— all three must be enabled for location data to be captured correctly.
