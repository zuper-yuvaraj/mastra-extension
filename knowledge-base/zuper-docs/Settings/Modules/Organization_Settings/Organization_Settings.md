# Configuring organization settings

The Organization settings section allows you to configure and manage organization-related preferences, including general settings and custom fields.

<Frame>
  **Navigation**: *Settings -> Modules -> Organization -> Organization General Fields*
</Frame>

## Organization general settings

Select the “**Settings**” module from the left panel. Under the “**Modules**,” choose the “**Organizations**.” Select the “**Customer/Contact General Settings**.”

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/Or1.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=7b08ce518ccdaffef1556a544166d5a8" alt="Or1 Pn" width="1908" height="871" data-path="images/Or1.png" />

* Allow Field Executive to view all Organization?

Yes: Toggle to Yes will enable viewing all organization access for field executives.

No: Toggle to No will disable viewing all organization access for field executives.

* Allow Team Leader to view all Organization?

Yes: Toggle to Yes will enable viewing all organization access for Team Leaders.

No: Toggle to No will disable viewing all organization access for Team Leaders.

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/Or2.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=631a126616ddf2e2bed631aee049c5d6" alt="Or2 Pn" width="1919" height="874" data-path="images/Or2.png" />

To save changes, click the **Save** button at the top right.

## Organization custom fields

Select the “**Settings**” module from the left panel. Under the “**Modules**,” choose the “**Organizations**.” Select the “**Organization custom fields**.”

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/Or3.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=85352381bfa9d93ab60a12b1a5c93789" alt="Or3 Pn" width="1902" height="871" data-path="images/Or3.png" />

Drag and drop the fields from the right panel.

Text

* Single-Line Input: This allows you to create a field to enter a single line of free text.
* Multi-Line Input: This allows you to create a field to enter multiple lines of free text.

Date

* Date Input: This allows you to create a field to select a specific date from a calendar.
* Time Input: This allows you to create a field where you can select a specific time.
* Date Time Input: This allows you to create a field where both date and time can be selected.

Selection

* Single-Selection: This allows you to create a radio input Field where one of the provided options can be selected.
* Multi-Selection: This allows you to create check boxes where the provided options can be checked.
* Drop-Down: This allows you to create a drop-down field with the required list of options.

Media

* Upload: This allows you to create a file input field to upload files.

Misc

* Look up : This allows you to create a file input field to look up the products from the parts and services module.

<Note>
  Note: You can also control the behavior and visibility of each field using the following options:

  * Mark as Required Field -  Makes the field mandatory to fill out before submitting the form.
  * Mark as Read Only—This option makes the field non-editable; users can view the value but cannot modify it.
  * Mark as hidden field- This hides the field from all users; it will not appear in the form interface.
  * Hide to FE/Technician- This option makes the field invisible to technicians or front-end users during form access.
</Note>

By following the outlined steps, you can easily organize the organization settings.
