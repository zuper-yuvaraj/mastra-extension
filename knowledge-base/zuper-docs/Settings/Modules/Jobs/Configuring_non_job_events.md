# Configuring Non Job Event

A non-job event is any activity that a field technician or other employees engage in unrelated to a specific job or work order. 

<Frame>
  **Navigation**: *Settings -> Modules -> Jobs -> Non Job Event Categories*
</Frame>

## Before you begin

<Warning>
  **Warning**: Non-Job Events are only visible and notified on the **Zuper Field Service** mobile app. They do not appear on the legacy Zuper Pro app. Ensure all field users are using the current app before configuring and assigning non-job events. See [Installing Zuper](/Getting_Started/Installing_Zuper) for app download links.
</Warning>

## Creating a new non-job event

1. Select the “**Settings**” module from the left navigation menu. Under “**Modules**,” choose “**Jobs**,” and select “**Non-Job Event Categories**" on the Job Settings page.

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/NJ1.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=ae49e5b6d7812ff85be8f50f92b78fe0" alt="NJ1 Pn" width="1907" height="870" data-path="images/NJ1.png" />

2. Click "**+ New Non Job Event**" to create the new category.

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/NJ2.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=4f15044580d5d4004f4a488ae9656c24" alt="NJ2.png" width="1909" height="860" data-path="images/NJ2.png" />

3. Enter the following details:

* **Category Name**: Enter the category name.
* **Category Color**: Choose the non-job event category color.
* **Category Description**: Enter the description.

<Note>
  **Note**: Check the "**Mark Attendees as busy**" checkbox to block the calendar.
</Note>

<img src="https://mintcdn.com/zuperinc/Nz5hYkeVtSkMQBoe/images/NJ3.png?fit=max&auto=format&n=Nz5hYkeVtSkMQBoe&q=85&s=328c46bc7dff29117430f08f1964291f" alt="NJ3 Pn" width="1912" height="871" data-path="images/NJ3.png" />

Creating these events informs dispatchers that the technician is unavailable for job assignments during this period, enabling better scheduling and resource management.

## Editing a non-job event category

To modify an existing event category:

* On the non-job event categories listing page, click the edit icon <Icon icon="pencil" /> under Actions next to the specific event that you want to update.
* Modify the necessary details in the Edit Non Job Event Category dialog box.
* Click **Update** to save the changes.

## Deleting a non-job event category

To delete a non-job event category: 

* On the non-job event categories listing page, click the delete icon <Icon icon="trash-can" color="#d31c1c" /> under Actions next to the specific event that you want to delete.
* A confirmation dialog box will appear.
* Click **Delete** to remove the category permanently.
