# Configuring Service Tasks

Service tasks in Zuper define specific job-related activities that field technicians must complete. These tasks standardize job execution, improve service efficiency, and help businesses track task completion. 

This guide provides a detailed walkthrough for creating, editing, and managing service tasks, ensuring that predefined procedures are followed during job execution. 

<Frame>
  **Navigation**: Settings -> Modules -> Jobs -> Service Tasks 
</Frame>

## Navigating to job service tasks 

To configure service tasks, follow these steps: 

* Select the "**Settings**" module from the left navigation menu.

<img src="https://mintcdn.com/zuperinc/WWRryQiWANaj5aW3/images/job1.png?fit=max&auto=format&n=WWRryQiWANaj5aW3&q=85&s=ab9ece2566f50f07b5fb8812f62ca75d" alt="Job1 Pn" width="1920" height="878" data-path="images/job1.png" />

* Click **Modules** and choose **Jobs** to open the Job Settings page.
* Click on **Service Tasks**.

<img src="https://mintcdn.com/zuperinc/p87sruICm1mYfxS7/images/job59.png?fit=max&auto=format&n=p87sruICm1mYfxS7&q=85&s=96ee6c055e673ba3b765f2d91f355a84" alt="Job59 Pn" width="1904" height="717" data-path="images/job59.png" />

* The service tasks listing page will appear, displaying all existing service tasks available for job assignments and team operations. 

<Note>
  **Note:** You can filter service tasks based on: **Status** (Active/Inactive), **User** (Task creator), and **Inspection Form** (Tasks linked to an inspection form)
</Note>

# Creating a new service task 

To create a new service task: 

* On the service tasks listing page, click **+ New Service Task**.

<img src="https://mintcdn.com/zuperinc/p87sruICm1mYfxS7/images/job60.png?fit=max&auto=format&n=p87sruICm1mYfxS7&q=85&s=d712888ef3eb0f778a2edc4b6ae93665" alt="Job60 Pn" width="1900" height="756" data-path="images/job60.png" />

* A **Create New Service Task** dialog box will appear.
* Enter the required details: 
  1. **Title** *(Mandatory)*: Enter a title for the service task (e.g., AC Filter Replacement, Electrical Inspection).
  2. **Description**: Provide a brief explanation of the task and its purpose.
  3. **Estimated Duration** *(Mandatory)*: Specify the estimated completion time of this service task in **days, hours, and minutes**.
  4. **Has Inspection Form**: Enable this option if the service task requires an **inspection form**. If enabled, select the appropriate form from the dropdown list.
* Click **Create** to save the new service task. 
  <img src="https://mintcdn.com/zuperinc/xykriCG8yCRPW26t/images/STR3.png?fit=max&auto=format&n=xykriCG8yCRPW26t&q=85&s=1fc02357b7853a7c4d1db88792336415" alt="STR3 Pn" width="1920" height="871" data-path="images/STR3.png" />

## Editing a service task 

To modify an existing service task: 

* On the service tasks listing page, click the kebab icon <Icon icon="ellipsis-vertical" color="#010101" />under **Actions** next to the specific task.
* Select **Edit Task**.

<img src="https://mintcdn.com/zuperinc/p87sruICm1mYfxS7/images/job61.png?fit=max&auto=format&n=p87sruICm1mYfxS7&q=85&s=82bdf5605a83feb21d2a388c63ba41b3" alt="Job61 Pn" width="1917" height="784" data-path="images/job61.png" />

* Update the necessary details.
* Click **Update** to save the changes. 

## Deactivating a service task 

To deactivate a service task: 

* On the service tasks listing page, click the kebab icon<Icon icon="ellipsis-vertical" color="#040404" />under **Actions** next to the specific task.
* Select **Deactivate Task**.

<img src="https://mintcdn.com/zuperinc/p87sruICm1mYfxS7/images/job62.png?fit=max&auto=format&n=p87sruICm1mYfxS7&q=85&s=3c8bff0058791df7e5968059aa7477b7" alt="Job62 Pn" width="1917" height="784" data-path="images/job62.png" />

* A confirmation dialog box will appear.
* Click **Deactivate** to disable the task. 

<Note>
  **Note:** Deactivated tasks can be reactivated if required. 
</Note>

## Deleting a service task 

<Info>
  **Important:** A service task must be **deactivated** before it can be deleted. 
</Info>

To delete a service task: 

* On the service tasks listing page, click the kebab icon <Icon icon="ellipsis-vertical" color="#0b0a0a" />under **Actions** next to the Inactive task.
* Select **Delete Task**.
* A confirmation dialog box will appear.
* Click **Delete Task** to remove the task permanently. You can also **activate** the task again, if needed.

<img src="https://mintcdn.com/zuperinc/Zk6TRRZZ87fvVXIt/images/STR5.png?fit=max&auto=format&n=Zk6TRRZZ87fvVXIt&q=85&s=a6914954f3d3f7318104299c59e44fde" alt="STR5 Pn" width="1903" height="875" data-path="images/STR5.png" />
