# Configuring Skillsets 

Skillsets in Zuper allow businesses to define and manage the skills required for various jobs.  Skillset can also be assigned to a User or a Job Category. Assigning skillsets helps in job scheduling by ensuring that the right field technicians with the necessary expertise are assigned to specific tasks.

This guide provides a detailed walkthrough on how to create, edit, and manage skills to streamline job allocation and ensure service quality.

<Frame>
  **Navigation**: \_Settings ->  Modules -> Jobs -> Skillsets \_
</Frame>

## Navigating to job skillsets 

To configure skillsets, follow these steps: 

* Select the "**Settings**" module from the left navigation menu.

<img src="https://mintcdn.com/zuperinc/WWRryQiWANaj5aW3/images/job1.png?fit=max&auto=format&n=WWRryQiWANaj5aW3&q=85&s=ab9ece2566f50f07b5fb8812f62ca75d" alt="Job1 Pn" width="1920" height="878" data-path="images/job1.png" />

* Click "**Modules"** and select "**Jobs"** to open the **Job Settings** page.
* Choose "**Skillsets**."

<img src="https://mintcdn.com/zuperinc/p87sruICm1mYfxS7/images/job9.png?fit=max&auto=format&n=p87sruICm1mYfxS7&q=85&s=86d6348c0b2650bc3da8eb4c0e67016c" alt="Job9 Pn" width="1920" height="878" data-path="images/job9.png" />

* The skillsets listing page will appear, displaying all existing skills for job and team needs. 

## Creating a new skillset

To add a new skill: 

* On the skillsets listing page, click "**+ New Skill**."

<img src="https://mintcdn.com/zuperinc/WWRryQiWANaj5aW3/images/job10.png?fit=max&auto=format&n=WWRryQiWANaj5aW3&q=85&s=d06c55b251e5c541afdb806c16575897" alt="Job10 Pn" width="1920" height="878" data-path="images/job10.png" />

* A **Create New Skill** dialog box will appear.
* Enter the required details:
  1. **Skill Name** *(Mandatory)*: Enter a descriptive name for the skill (e.g., Electrical Repair, HVAC Maintenance).
  2. **Skill Validity (Years)**: Specify how long the skill remains valid before requiring renewal (e.g., 2 years).
  3. **Skill Description** *(Mandatory)*: Provide a brief description of the skill, including its purpose and usage. 
* Click "**Create"** to save the new skill. 

<img src="https://mintcdn.com/zuperinc/WWRryQiWANaj5aW3/images/job11.png?fit=max&auto=format&n=WWRryQiWANaj5aW3&q=85&s=7eb876ea7dfac27d0891173528b620a0" alt="Job11 Pn" width="1920" height="878" data-path="images/job11.png" />

Once created, the skill will appear in the listing page with details such as: 

1. **Skill Name**
2. **Skill Description**
3. **Skill Validity**
4. **Created By** (User who created the skill)
5. **Created On** (Date & time of creation) 

## Editing a skillset

To modify an existing skill: 

* On the skillsets listing page, click the pencil icon <Icon icon="pencil" color="#060606" /> next to the skill you want to update.

<img src="https://mintcdn.com/zuperinc/WWRryQiWANaj5aW3/images/job12.png?fit=max&auto=format&n=WWRryQiWANaj5aW3&q=85&s=c2cdb9a80617ada11e82b169cddf30ab" alt="Job12 Pn" width="1906" height="877" data-path="images/job12.png" />

* The **Edit Skill** dialog box will open.
* Make the necessary changes.
* Click "**Update"** to save the changes. 

## Deleting a skillset

To remove a skill permanently: 

* On the skillsets listing page, click the delete icon <Icon icon="trash-can" color="#090909" /> next to the skill you want to remove.

<img src="https://mintcdn.com/zuperinc/WWRryQiWANaj5aW3/images/job13.png?fit=max&auto=format&n=WWRryQiWANaj5aW3&q=85&s=4f8121ae71411b3843bb02cbbba5577e" alt="Job13 Pn" width="1906" height="877" data-path="images/job13.png" />

* A confirmation dialog box will appear.
* Click "**Delete"** to confirm and permanently remove the skill.
