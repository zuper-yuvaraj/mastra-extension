# Enable Modules

## Overview

Zuper offers a range of features and add-on modules that extend what your team can do — from advanced quoting and purchasing to customer financing and offline field support. All modules are enabled by Zuper Support on your behalf.

This article lists the available modules, describes what each one does, and explains how to contact Support to get them activated for your account.

## Available features & modules

The table below describes the available add-on modules in Zuper.

| Module | Function | |
| - | - | - |
| [**Customer Portal**](https://docs.zuper.co/Customer_Portal/Login_to_customer_portal) | Your customers get a self-service portal where they can view their jobs, invoices, and service history. | |
| [**Service Task**](https://docs.zuper.co/Work_Order_Management/Jobs/Creating_and_managing_service_tasks) | Add individual tasks inside a job to track each work step in more detail. | |
| [**Offline Support**](https://docs.zuper.co/Zuper_Mobile_Apps/Using_Zuper_Offline) | Lets field executives use the Zuper mobile app without an internet connection. Data syncs automatically once the connection is back. \| | |
| [**Consumer Financing (Wisetack)**](https://docs.zuper.co/Integrations/Accounting_and_payments/Zuper_Wisetack) | Lets your customers apply for financing directly from their invoice or quote. | |
| [**Proposal**](https://docs.zuper.co/Accounting/Proposal) | Send service proposals to customers before creating a formal quote. | |
| **Distance and Travel Time [(Dispatch Board)](https://docs.zuper.co/Dispatch/Overview)** | Displays estimated travel distance and time for each technician on the Dispatch Board, so you can make faster, better-informed scheduling decisions. | |
| [**Transfer Orders**](https://docs.zuper.co/Inventory_Management/transfer/Create_Transfer) | Transfer parts and inventory between locations using transfer order records. | |
| [**Price List**](https://docs.zuper.co/Inventory_Management/Pricelists/Overview) | Create and manage price lists for parts and services. Apply them directly to quotes and invoices. | |

## How to request a module

To enable any module listed above, contact Zuper Support with the following information:

1. Your company name and Zuper account name.
2. The name of the module you want to enable.
3. Your preferred activation date, if you have one.

Reach Zuper Support at [support@zuper.co](mailto:support@zuper.co).

<Info>
  Zuper Support will confirm activation and share any setup steps required on your side before the module goes live.
</Info>

## FAQs

1. **Will a module be enabled for my entire account or just specific users?** \
   Modules are enabled at the account level. Once active, all users in your account can access the module. Some modules — for example, Customer Portal — have separate permission settings that let you control which user roles can use them. Zuper Support will advise you on this when activating.
2. **What happens to existing data if a module is disabled?** \
   Disabling a module hides it from your account but does not delete any existing data. Records created while the module was active remain in the system and are restored if the module is re-enabled. Contact [Support](mailto:support@zuper.co) before disabling a module if you have concerns about your data.
3. **I requested a module but cannot see it in the app. What should I do?** \
   Ask your team members to log out and log back in. If the module still does not appear, verify that your user role has the correct permissions to access it. If the issue continues, contact [Support](mailto:support@zuper.co).
4. **How long does activation take?** \
   Activation timelines vary by module. Modules that involve third-party integrations — for example, Consumer Financing (Wisetack) — might take longer as they require external setup steps. Zuper Support will give you an estimated timeline when you raise the request.
5. **Can I request a module that is not listed here?** \
   Yes. Reach out to [Zuper Support](mailto:support@zuper.co) or your Customer Success Manager to discuss your requirements. If the capability exists on your plan, the team will guide you through enablement.
