# Generating API Key

You will require an API key to make HTTP API calls to Zuper.

To generate API Key, please follow the below steps:

1. Login to Zuper web app, Click on **Settings** from the left menu.
2. Under 'Developer Hub' click on "API Keys".

<Image border={false} src="https://files.readme.io/090410c5d5852d11b087de6672e52edcbbff3dfc402d07526f333031bb909d8f-image.png" />

<br />

3. Click on "New API Key"
4. You can give a "API Key Name" to easily identify and click on create. Check the "Read-only" box to restrict the API key to only GET API calls.

<Image border={false} src="https://files.readme.io/322e6c044fcf61520db4a849b3de27e430d2afb42bf7c4e8c701fe2bd3ea2ad9-image.png" />

5. Your API key will be generated and displayed.

**Note:** API Key inherits all permissions of the user for which the key is created against.
