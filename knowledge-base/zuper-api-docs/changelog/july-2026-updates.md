# July 2026 Updates

🆕 **Edit Partially Paid Invoices** – Invoices in **Partially Paid** and **Paid** states can now be edited. Additionally, custom fields, Estimate Date, and Expiry Date remain editable even after an [estimate has been converted into an invoice](https://developers.zuper.co/reference/update-quote-details).

🆕 **All-Day Scheduling** – Added support for creating all-day schedule entries on [Jobs](https://developers.zuper.co/reference/create-job), making it easier to manage full-day [assignments](https://developers.zuper.co/reference/update-job-assignment).

🆕 **Multi-User Time Off** – Added support for [creating](https://developers.zuper.co/reference/create-timeoff) and [managing](https://developers.zuper.co/reference/create-timeoff-request-copy) time-off requests for multiple users in a single operation.

🆕 **Approval Workflow for Contract Renewals** – Contract [renewals](https://developers.zuper.co/reference/update-approval-status-copy) now automatically trigger the configured [approval workflow](https://developers.zuper.co/reference/activatedeactivate-service-contract-copy), ensuring renewed contracts follow the required approval process.

🆕 **Purchase Tax Support** – Added product-level [purchase tax](https://developers.zuper.co/reference/update-a-product) configuration, which is automatically applied during [Product Inward](https://developers.zuper.co/reference/create-inward-transcation) and [Purchase Order](https://developers.zuper.co/reference/create-purchase-order) workflows.

🆕 **Page-Level Acknowledgements** – Added page-level acknowledgement support in [Proposal Layouts](https://developers.zuper.co/reference/update-a-proposal) with live preview, [PDF generation](https://developers.zuper.co/reference/create-a-proposal-template), and signature validation.

🆕 **Quote Sent Date** – Introduced a new **Sent Date** field for [Quotes](https://developers.zuper.co/reference/get-all-quote), enabling improved listings, reporting, and automated [follow-up reminder](https://developers.zuper.co/reference/send-a-quote) workflows.

🆕 **Follow-Up Reminders Based on Sent Date** – Automated follow-up reminders can now be configured based on the date a [Quote](https://developers.zuper.co/reference/send-a-quote) or [Estimate](https://developers.zuper.co/reference/update-quote-details) was sent to the customer.

🆕 **Developer Hub Permission** – Added a dedicated role-based permission to control access to the Developer Hub.

🆕 **Show Deposit Toggle in Proposal Layouts** – Introduced a configurable deposit visibility toggle in the [Proposal Layout Builder](https://developers.zuper.co/reference/update-a-proposal), allowing deposits to be shown or hidden in both the [Proposal PDF](https://developers.zuper.co/reference/create-a-proposal-template) and the public proposal page.

🆕 **Bid Engine Measurement Upload** – Added support for [uploading](https://developers.zuper.co/reference/upload-measurement) measurement files generated by Bid Engine.

🆕 **Pitch Gauge Measurement Upload** – Added support for manually [uploading](https://developers.zuper.co/reference/upload-measurement) Pitch Gauge [measurement](https://developers.zuper.co/reference/create-measurement) XML files.

🆕 **CPQ Template Reordering** – [Proposal](https://developers.zuper.co/reference/update-proposal-options) and CPQ template options can now be [reordered](https://developers.zuper.co/reference/reorder-package), providing greater flexibility when configuring proposals.

🆕 **Negative Totals in Estimates** – [Estimates](https://developers.zuper.co/reference/update-quote-details) and [Quotes](https://developers.zuper.co/reference/create-a-quote) now support negative total values, enabling advanced pricing adjustments and credit scenarios.

⭐ **Commission Listing Enhancements** – Commission listing APIs now include the current Job Status and associated Job Category in both listing and metadata responses.

⭐ **AR Aging Statistics Filters** – Added Customer, Due Date, and Aging Period filters to the AR Aging Statistics API for more flexible reporting.

⭐ **Proposal Layout Improvements** – Proposal PDFs now display addon quantities based on visibility settings, include approved quote line items within accepted options, and provide improved image cropping and resizing in the layout editor.

⭐ **Automatic Customer Detail Synchronization** – Customer information updates are now automatically synchronized across Estimates, Invoices, Jobs, Requests, Projects, Contracts, and Assets.

⭐ **Highest Price Validation for Product Inward** – Added support for enforcing configurable maximum purchase price limits during [Product Inward](https://developers.zuper.co/reference/create-inward-transcation).

⭐ **Contract Reminder Improvements** – Contract reminders are now sent even when a contract template has not been configured.

⭐ **Automatic Proposal PDF Attachment** – Proposal PDFs are now automatically attached to Quotes after a proposal is accepted by the customer. *(Applicable only for Layout Templates.)*

⭐ **Signature Handling on Layout Changes** – Estimate updates now automatically preserve and apply signatures when the Proposal Layout Template is changed.

⭐ **Activity Tracking Enhancements** – Added activity log entries for comment actions and user update operations to improve audit visibility.

⭐ **Note Activity & Offline Archival Improvements** – Updated activity messages for note-related actions and improved offline archival handling.

⭐ **Material Request & Purchase Order Counts** – Jobs now maintain Material Request and Purchase Order counts to improve reporting performance.

⭐ **Measurement Validation Improvements** – Prevented duplicate measurement token names within a category and introduced internal measurement status tracking.

⭐ **Update Job API Enhancements** – Added support for removing all Service Tasks when updating a Job Category.

⭐ **Finance Statistics Improvements** – Updated Job and Project Finance Statistics APIs to correctly calculate and include surcharge amounts.

⭐ **Bulk Quote Color Updates** – Added a bulk API for updating color options across multiple Quotes.

⭐ **SRS Supplier Integration Enhancements** – Delivered multiple API improvements and workflow enhancements for SRS supplier integrations.

⭐ **Purchase Order & Work Order Enhancements** – Added multiple improvements and API updates across Purchase Orders and Work Orders.

🐞 **Document API Fixes** – Resolved multiple stability and correctness issues across the Document APIs.

🐞 **PDF Generation Improvements** – Fixed multiple PDF generation and rendering issues to improve document stability and reliability.

🐞 **Timelog Update Fixes** – Fixed issues affecting Timelog updates to ensure accurate time tracking.

🐞 **Duplicate Asset Prevention** – Prevented duplicate Asset creation during Job creation and update operations.

🐞 **Receivables Fixes** – Corrected receivables calculations for invoices marked as **BAD\_DEBT** and **ARCHIVED** during bulk actions.

🐞 **Customer Portal PDF Fixes** – Resolved Estimate and Invoice PDF rendering issues within the Customer Portal.
